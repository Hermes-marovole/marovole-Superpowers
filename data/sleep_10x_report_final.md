## 五、关键发现与热门话题

### 1. 用户情绪表达矩阵

基于标题+描述的文本分析，负面情绪出现频次：

- **"睡不着"** — 高频词（出现在 400+ 条标题/描述中）
- **"焦虑"** — 高频词（350+ 条）
- **"崩溃"** — 高频词（100+ 条）
- **"怎么办" / "求助"** — 高频词（150+ 条）
- **"痛苦" / "煎熬" / "折磨"** — 中频词（80+ 条）
- **"想死" / "看不到希望" / "生不如死"** — 高频于某些极端个案（10+ 条）

### 2. 用户自救行为路径

按数据中出现的用户行为链条排序：

1. **初始阶段:** "睡不着" → "玩手机" → "越玩越精神" → "凌晨三点还清醒"
2. **尝试自助:** "吃褪黑素" → "吃了没用" → "加量" → "停了更严重"
3. **寻求医学:** "去看中医" → "喝了酸枣仁汤" → "好像有点用" → "又不行了"
4. **非药物探索:** "开始练瑜伽" → "睡前冥想" → "ASMR" → "白噪音" → "有的有用有的没用"
5. **补充剂尝试:** "听说镁有用" → "买了甘氨酸镁" → "好像深度睡眠多了" → "继续坚持"
6. **认知改变:** "接受不完美睡眠" → "不强迫入睡" → "反而睡得好了" → "CBT-I 理念"

### 3. 性别差异线索

- **男性表达** 较少在社交媒体上公开讨论失眠，多出现在 Reddit/Quora 等技术社区，关注"Magnesium + L-theanine stack"
- **女性表达** 在知乎/小红书/豆瓣上极为活跃，关注产后、更年期、美容（脱发/皮肤）、情绪，多次出现"老公打呼噜/睡前看手机影响到我"
- **学生群体** 集中在"考研/高考失眠""报复性熬夜""宿舍矛盾导致失眠"

## 七、数据质量与方法说明

1. **采集方法:** 基于 DuckDuckGo web_search API，183 次查询覆盖中英文搜索
2. **去重策略:** URL 唯一性去重（2,103 条唯一 URL）
3. **内容粒度:** 每条记录包含标题、URL、描述、来源标签、触发查询词
4. **深度提取尝试:** 对 50 个高价值 URL 尝试详情页提取，受限于 web_extract 工具的成功率，暂未纳入主数据集
5. **目标达成率:** 相对初始 488 条，当前 2,103 条约为 **4.3 倍**；若计入原始目标"扩大10倍"，则需 4,880 条
