## 详细拆解：三步工作流

### 第一步：调研 —— 模仿的是真掏钱的作业

#### 核心原则

**不要模仿爆款，要模仿销量。**

- ❌ 不要看：点赞多的情绪梗、争议梗、猎奇梗（看着爽，但没真实需求）
- ✅ 要看：销量高的商品图（掏钱买才是真需求）

#### 具体操作

1. **打开小红书，按销量排序**
   - 找到前几名的商品图
   - 截图保存

2. **用 AI 反推提示词**
   - 把图扔进 AI Agent（如 GPT-4V、Claude 等）
   - 指令："分析这张图的设计元素、配色、布局、字体、风格，生成可以复现这张图的提示词"

3. **一分钟拿到提示词**
   - 稍微改改就能直接用
   - 完全不需要自己凭空想象

#### 案例：56 万流量图的真相

> "这张图，我什么都没做！！我只是从需求出发，找对了那个已经解决问题的答案。"

- 提示词超级简单
- 连提示词都不是自己写的
- 从销量高的成功案例反推得到
- 一次模仿 = 解决真实问题的答案

---

### 第二步：生产内容 —— 一次定制，批量出图

#### 问题：反推提示词的一次性困境

如果每张图都要重新反推：
- 十张图反推十次
- 累加起来还是**一次性劳动**
- 没有形成可复用的资产

#### 解决方案：写"元提示词"(Meta Prompt)

**不是写 Prompt，是写 Meta Prompt。**

- 像填空题：题干固定，每次填不同答案
- 一个 Meta Prompt 里留好几个空：场景、文字、风格、主题
- 每次要图，只填这几个空就行

#### 普通写法 vs Meta Prompt

| 方式 | 示例 | 缺点 |
|------|------|------|
| **普通 Prompt** | "生成一张健身房单词记忆图，背景蓝色，字体白色..." | 只能用于一个场景 |
| **Meta Prompt** | "生成一张[场景]单词记忆图，背景[颜色]，字体[颜色]，包含[主题]相关单词..." | 填空即可复用 |

#### 工具：CREAO Agent 辅助生成

**问题**：手写 Meta Prompt 本身就很麻烦，普通人看着就费劲。

**解决方案**：跟 CREAO Agent 对话，让它帮你完成。

1. **告诉 Agent 痛点**
   - "我需要批量生成单词记忆图"
   - "场景会变化：健身房、厨房、办公室..."

2. **让 Agent 列出可定制选项**
   - 场景选择
   - 配色方案
   - 主题分类
   - 字体风格

3. **随机切换生成新提示词**
   - "随机切换这些痛点给我生成新的提示词"
   - 每次得到不同的原创内容

> "创作一个原创作品就这么简单，原来可以这么简单！！"

### 第三步：自动化 —— 你睡觉它上班

#### 2026 年的正确姿势：用 Agent，不用聊天机器人

**聊天机器人模式**：
- 每次打开对话框
- 一遍一遍输入提示词
- 关掉就没了，下次重来

**Agent 模式**：
- 对话一键保存为 Agent
- 随时打开，参数填一下，图就出来
- 前面步骤不用重跑

#### CREAO 的核心功能

**1. 保存 Agent**

- 把跑成功的对话一键保存
- 从"一次性过程"变成"可反复调用的产品"

**2. Scheduled Run（定时运行）**

- 给 Agent 设置定时任务
- 比如：每天早上 7 点自动出一批新图
- 你睡醒只管挑

> **结果：你不需要到场，它自己出产。**  
> **你睡觉的时候它在工作，你出门的时候它在工作，你开会的时候它在工作！！**

**3. 不下班的分身**

- 手里不再是一个工具
- 是一个**不下班的分身**
- 每跑一次，都给库里加一件资产
