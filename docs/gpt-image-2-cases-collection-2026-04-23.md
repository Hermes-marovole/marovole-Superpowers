| 亮点 | 说明 |
|------|------|
| **中文渲染新突破** | 课本、报纸、药方、书法都能生成 |

## 实操案例与 Prompt 模板

### 案例一：图鉴式拆解图（展板级别）

**核心能力**：复杂信息结构化、中文标注、博物馆级视觉呈现

**效果描述**：
国家博物馆展板级质感，结构拆解、中文标注、材质说明、纹样寓意、色彩含义一应俱全，高级、克制、可收藏。这个提示词是通用模板，把【主题】换成汉服、凤冠、盔甲、器物、古籍、兵器等任何东西，都能直接出图鉴。

**原帖链接**：https://x.com/MrLarus/status/2045504669401653414

**Prompt 模板**：
```
请根据【主题】自动生成一张"博物馆图鉴式中文拆解信息图"。

要求整张图兼具真实写实主视觉、结构拆解、中文标注、材质说明、纹样寓意、色彩含义和核心特征总结。你需要根据【主题】自动判断最合适的主体对象、服饰体系、器物结构、时代风格、关键部件、材质工艺、颜色方案与版式结构，用户无需再提供其他信息。

整体风格应为：国家博物馆展板、历史服饰图鉴、文博专题信息图，而不是普通海报、古风写真、电商详情页或动漫插画。背景采用米白、绢纸白、浅茶色等纸张质感，整体高级、克制、专业、可收藏。

版式固定为：
- 顶部：中文主标题 + 副标题 + 导语
- 左侧：结构拆解区，中文引线标注关键部件，并配局部特写
- 右上：材质 / 工艺 / 质感区，展示真实纹理小样并附说明
- 右中：纹样 / 色彩 / 寓意区，展示主色板、纹样样本和文化解释
- 底部：穿着顺序 / 构成流程图 + 核心特征总结

若主题适合人物展示，则以真实人物全身站姿为中央主体；若更适合器物或单体结构，则改为中心主体拆解图，但整体仍保持完整中文信息图形式。所有文字必须为简体中文，清晰、规整、可读，不要乱码、错字、英文或拼音。重点突出真实结构、材质差异、文化说明与图鉴气质。

避免：海报感、影楼感、电商感、动漫感、cosplay感、乱标注、错结构、糊字、假材质、过度装饰。
```

**适用场景**：
- 文物/服饰科普内容
- 产品说明书设计
- 教育类信息图
- 博物馆数字化展示

### 案例二：古文真迹 + 书法临摹帖

**核心能力**：中文书法渲染、文学情感理解、字体风格模仿

#### 2.1 还原千古名篇

**效果描述**：
兰亭集序、出师表、滕王阁序、岳阳楼记……惟妙惟肖，满页密集中文书法没有崩坏！

**原帖链接**：https://x.com/MrLarus/status/2046201836525302032

**Prompt**：
```
生成【名篇名称】真迹图片
```

**进阶技巧**：
想效果更好可以加"王羲之体 / 颜真卿风格 / 注入情绪"等描述。

#### 2.2 进阶版（注入情绪）

**核心洞察**：
AI 无法替代人类的艺术与情感，但它已经在理解汉语文学里的情绪了，笔墨变化明显更丰富。

**原帖链接**：https://x.com/MrLarus/status/2046240175777259752

**Prompt**：
```
生成【名篇名称】真迹图片，请结合作品情感核进行生图
```

**效果差异**：
相比基础版，注入情感描述后，笔墨的浓淡变化、节奏感会更贴近原作的情感基调。

**提示词特点**：

## 使用技巧总结

### 1. 中文渲染优化

| 场景 | 建议 |
|------|------|
| 书法生成 | 指定字体风格（王羲之体/颜真卿等） |
| 复杂排版 | 明确版式结构（顶部/左侧/右上等） |
| 密集文字 | 强调"清晰、规整、可读" |

### 2. Prompt 设计原则

- **极简原则**：有时候一句话就够了，AI 会自己补全
- **角色设定**：告诉 AI 它是"博物馆展板设计师"、"书法家"等
- **负面约束**：明确说明"避免海报感、影楼感、电商感"等

### 3. 迭代优化流程

```
初版生成 → 指出问题 → 追问修改 → 满意输出
     ↑___________________________|
```

不需要从零重跑，直接在对话中迭代。
