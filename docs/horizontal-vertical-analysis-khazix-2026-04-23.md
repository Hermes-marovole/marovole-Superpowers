## 横纵分析法核心框架

### 两条轴线的定义

#### 第一条轴：纵向（历时分析）
沿着**时间线**，把一个事物从诞生到现在的完整故事还原出来：
- 它怎么来的？
- 谁做的？
- 中间经历了什么？
- 为什么在某个节点突然爆发或掉头？

**目标**：理解事物的历史与因果。

#### 第二条轴：横向（共时分析）
在当下这个时间点，把它跟**同赛道的其他事物**放在一起比较：
- 它跟竞品有什么不同？
- 用户为什么选它不选别的？
- 它在整个赛道里是什么位置？

**目标**：理解事物的位置与差异。

#### 关键一步：交叉分析
把两条轴交叉起来看，你会发现单看任何一条轴都看不到的东西：
- 今天的某个优势，可能是三年前一个不起眼的决策慢慢积累出来的
- 今天的某个短板，可能是当初一个合理的选择变成了包袱

## 学术理论基础

横纵分析法并非凭空创造，而是融合了多个经典学术框架：

### 1. 索绪尔的语言学分析（历时与共时）
瑞士语言学家**费尔迪南·德·索绪尔**（Ferdinand de Saussure）提出：
- **历时分析（Diachronic）**：研究语言随时间演变的轨迹
- **共时分析（Synchronic）**：研究某一时间点上语言系统的结构关系

### 2. 社会科学的纵向研究与横截面研究
- **纵向研究（Longitudinal Study）**：追踪同一对象随时间的变化
- **横截面研究（Cross-sectional Study）**：在某一时间点观察多个对象的截面状态并做横向对比

### 3. 商业竞争战略分析
结合了商业分析中的竞争战略视角，关注：
- 竞争格局
- 差异化定位
- 用户选择逻辑

### 两种使用方式

#### 方式一：Prompt 版本（轻量级）
**适用场景**：
- 复制粘贴到任何 AI 对话
- 支持 Deep Research 的模型（ChatGPT DeepResearch、Claude 深度研究、豆包专家模式、DeepSeek 专家模式等）

**使用步骤**：
1. 复制 Prompt 内容
2. 修改「研究对象」等式后的词组
3. 发送给 AI，开始深度研究

**Prompt 核心结构**：
```
研究对象 = [你想研究的事物]

请按照以下框架进行深度研究：
1. 纵向分析：追溯历史演变、关键节点、因果逻辑
2. 横向分析：对比竞品、定位差异、竞争格局
3. 交叉判断：综合分析，得出结论

要求：
- 使用易读的文风（融入卡兹克写作 Skill 能力）
- 报告长度约一万字
- 输出格式清晰，便于阅读
```

#### 方式二：Skill 版本（重量级）
**适用场景**：
- 使用 Cowork、Claude Code、Codex 等 Agent 工具
- 需要自动联网搜索、生成 PDF 报告

**安装方法**：
1. 将 `hv-analysis` 目录放入 Agent 的 Skill 目录
2. 对 Agent 说：「帮我研究一下 xxx」
3. Agent 自动执行横纵分析法框架

**Skill 版本优势**：
- ✅ 自动联网搜索信息
- ✅ 集成 arXiv API（研究学术问题时自动查询论文）
- ✅ 生成排版精美的 PDF 研究报告
- ✅ 文风更易读，比 Prompt 版本更自由丰富

## 局限性与注意事项

### 1. 不是万能的
- 能快速建立认知框架，但**替代不了真正深入的、亲自下场的研究**
- 更适合作为研究的**起点**，而非终点

### 2. AI 信息准确性
- 虽然 AI 幻觉已大幅降低，但仍**可能出现不准确信息**
- 建议拿到报告后，针对有疑问的点**人工验证**

### 3. 工具依赖性
- 报告质量与使用的**模型和工具**有很大关系
- 推荐：ChatGPT DeepResearch、Claude 深度研究（10 分钟以上任务）
- 普通联网搜索工具效果可能大打折扣（不到 1 分钟的任务）

### 4. 好奇心是前提
> "没有好奇心，有再好的方法论也是摆设。有了好奇心，哪怕方法笨一点，你也总会找到答案的。"
