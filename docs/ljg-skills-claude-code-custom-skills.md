## 执行摘要

2026 年 5 月 11 日，提示词工程领域标志性人物李继刚在 X 发布了一条简洁的推文——"给这个世界的一份答卷"，链接指向他的 GitHub 仓库 `lijigang/ljg-skills`。这份"答卷"是一套为 Claude Code 量身打造的自定义技能集（Skills），包含 **17 个独立技能** 和 **2 条工作流**，涵盖内容可视化、概念解剖、论文阅读、深度写作、投资分析、旅行研究、演讲铸造等维度，累计获得 **4.2k Stars** 与 **488 Forks**。

与市面常见的 AI 提示词合集不同，这套技能集的核心特征在于：**每一个技能都有鲜明的个人方法论烙印**，不是"通用模板"的堆砌，而是李继刚个人思维工具的外化——从"八维概念解剖"到"追本之箭"，从"内容铸卡"到"圆桌讨论"，每个技能的名字本身就已经暗示了其独特的认知框架。

## 核心亮点

### 1. 完整覆盖「输入→处理→输出」全链路

| 环节 | 代表技能 | 功能 |
|------|----------|------|
| **信息输入** | `ljg-read`（伴读）、`ljg-paper`（论文阅读） | 结构化吸收文本与论文 |
| **概念加工** | `ljg-learn`（概念解剖）、`ljg-think`（追本之箭）、`ljg-rank`（降秩引擎） | 深度理解与本质挖掘 |
| **内容表达** | `ljg-writes`（写作引擎）、`ljg-plain`（白话引擎）、`ljg-qa`（信息提问机） | 多形态内容生产 |
| **视觉输出** | `ljg-card`（内容铸卡）、`ljg-present`（演讲铸造器） | 一键生成 PNG 卡片 / HTML 演讲 |
| **生活场景** | `ljg-travel`（旅行研究）、`ljg-relationship`（关系分析） | 跨领域知识应用 |
| **自我管理** | `ljg-skill-map`（技能地图）、`ljg-push`（推送引擎） | 技能管理与同步 |

### 2. 双格式支持：Org-mode + Markdown

技能集同时维护两个 branch：
- `master`（默认）：Org-mode（`.org`），面向 Emacs / Denote 用户
- `md`：Markdown（`.md`），面向 Obsidian / VSCode / Notion 用户

安装时通过 `#md` 后缀即可切换格式，功能完全一致。

### 3. 安装极简，一行命令

基于 Vercel Labs 开源的 `skills CLI`（`npx` 驱动），一行命令完成全局安装：

```bash
# 安装全部技能（全局，org-mode 格式）
npx skills add lijigang/ljg-skills -g --all

# 安装全部技能（Markdown 格式）
npx skills add lijigang/ljg-skills#md -g --all
```

## 发布者洞察

### 个人背景

李继刚，X 平台 Verified 账号，个人简介为「我与 AI 周旋久，宁做我」。他是中文提示词工程领域最具影响力的独立实践者之一，以精练、锋利、极具个人风格的提示词设计著称。他的技能命名往往只用两三个汉字（如「铸」「追本」「降秩」「伴读」），却承载着完整的认知方法论。

### 核心理念

从各技能的 SKILL.md 中，可以提炼出李继刚设计这套技能集的三条核心信念：

**信念一：技能是「个人思维工具」的外化，不是通用模板**

以 `ljg-learn`（概念解剖）为例，它要求从八个维度（历史、辩证、现象、语言、形式、存在、美感、元反思）切开一个概念，最后压成一句顿悟。这不是一个"解释概念"的通用模板，而是李继刚个人认知习惯的代码化——他看任何新概念时，会自动触发这八把刀。

**信念二：输出格式是思考的一部分**

几乎每个技能都强制使用 org-mode（或 Markdown），并配有严格的文件命名规范（Denote 风格时间戳）、目录约定（`~/Documents/notes/`），以及 ASCII Art 图表约束。这些"格式纪律"不是装饰，而是为了确保思考成果可被长期检索、跨设备同步、与知识库无缝衔接。

**信念三：AI 不是替你思考，是陪你思考**

`ljg-read`（伴读）的核心理念最能说明这一点："不是替你读，是陪你走进去。扫清语言障碍只是起手式，真正的活儿是让你撞见自己从没想过的问题。" 这与市面上大多数"AI 替你总结"的工具形成了鲜明对照。

## 技能详解

### 内容可视化

#### `ljg-card` — 内容铸卡（v2.3.0）

将任何内容铸成 PNG 视觉卡片。七种模具：

| 参数 | 模具 | 尺寸 | 说明 |
|------|------|------|------|
| `-l`（默认） | 长图阅读卡 | 1080 × auto | 单张，内容自动撑高 |
| `-i` | 信息图 | 1080 × auto | 内容驱动的自适应视觉布局 |
| `-m` | 多卡 | 1080 × 1440 | 自动切分为多张阅读卡片 |
| `-v` | 视觉笔记 | 1080 × auto | 编辑式杂志专题（问题→失败→转折→顿悟→命名） |
| `-c` | 漫画 | 1080 × auto | 日式黑白漫画风格，动态选择漫画家视觉语言 |
| `-w` | 白板 | 1080 × auto | 白板马克笔风格，结构化框图 |
| `-b` | 大字 | 1080 × 1440 | 碑刻大字 + 和紙 + 外阴影，小红书附件风格 |

**依赖**：Playwright（安装后需额外执行 `npm install && npx playwright install chromium`）

**品味准则**：反 AI 生成痕迹——禁 Inter 字体、禁纯黑、禁三等分卡片、禁居中 Hero、禁 AI 文案腔、禁假数据。

---

### 概念与思维工具

#### `ljg-learn` — 概念解剖

拿到一个概念，从八个方向切开，最后压成一句顿悟。

**八刀结构**：
1. **历史**：最早从哪冒出来 → 怎么变的 → 哪一步拐成了今天的意思
2. **辩证**：它的反面是什么 → 正反碰撞后，更高一层的理解是什么
3. **现象**：扔掉所有预设，回到事情本身 → 用一个日常场景把它还原出来
4. **语言**：拆字源（中/英/希腊/拉丁）→ 画出相邻概念的语义网
5. **形式**：写一个公式或形式化表达 → 公式在哪里失效
6. **存在**：这个概念改变了人怎么活着
7. **美感**：它美在哪？用一个具体意象呈现
8. **元反思**：我们在用什么隐喻理解它？这个隐喻挡住了什么？

**输出**：org-mode 文件，写入 `~/Documents/notes/{时间戳}--概念解剖-{概念名}__concept.org`

---

#### `ljg-think` — 追本之箭

输入一个观点，一路向下钻到不可再分的本质。

**钻的逻辑**：表象之下必有机理 → 机理之下必有原理 → 原理之下必有公理。

**三条铁律**：
1. **纵向，不横向**——每次下钻必须回答"为什么是这样"，不是"还有什么"
2. **单刀直入**——不旁征博引，不铺陈背景，直取要害
3. **层层惊叹**——每一次深入都让人感到"原来下面还有一层"

**到底的标志**：触及人性基本结构、物理定律、逻辑本身、存在的悖论。

---

#### `ljg-rank` — 降秩引擎

给一个领域，找出背后不可再少的独立生成器。

（核心理念：用线性代数的"降秩"直觉，迁移到认知领域——一个领域的全部现象，可能由极少数底层变量生成。）

---

### 阅读与学习

#### `ljg-read` — 伴读（v1.0.0）

不是替你读，是陪你走进去。

**核心流程**：
1. **Phase 0（全局地图）**：一句话摘要 + 段落分类（骨/肌/筋）+ 全文结构地图 + 五维段前扫描
2. **Phase 1（逐段伴读）**：英文三层翻译（信→达→雅）+ 结构标注 + 深度提问 + 跨领域旁逸

**翻译理念**：信是不歪，达是懂了，雅是住下来了。

---

#### `ljg-paper` — 论文阅读（v4.9.0）

读论文不是做学术，是猎取思想。

**四问结构**：
1. 论文在解决什么问题（具体到一个例子）
2. 作者用什么招数解的（机制 + 设计选择的理由）
3. 核心发现是什么（包括最反直觉的副发现）
4. 你（读者）能带走什么洞见

**关键约束**：如果输出在任何一点上让外行卡住，就是失败。凝练只在 title 上追求，正文该展开就展开。

---

#### `ljg-paper-river` — 论文溯源

倒读法：递归挖前序论文（最多 5 层）+ 最新进展，从源头讲述问题演化史。

---

#### `ljg-word` — 单词精通

深度拆解一个英语单词的核心语义和顿悟时刻。

---

### 写作与表达

#### `ljg-writes` — 写作引擎（v6.3.0）

像手术刀剖开一个观点，一层层剥到底。1000–1500 字。

**姿态**：外科医生的手，朋友的口。下刀时冷静、精准、不抖；讲话时平常、直接、不绕。

**语言纪律**：
- 能两个字说的不用四个字
- 砍：机械连词、形容词通胀、软化词
- 翻译腔免疫：这句翻回英文再翻回中文，还是原样吗？是→八成翻译腔，重写
- 计算机体系是母语。缓存、调度、编译、虚址——需要时用，像呼吸，不像引用

**禁止**：
- 不用群体代言（「程序员都知道」）
- 不自标深度（禁用「再深入一层」「最深的一层是」这类宣告）

---

#### `ljg-plain` — 白话引擎

把任何内容改写到聪明的十二岁小孩也能懂。

---

#### `ljg-qa` — 信息提问机

把文章/论文/书的核心观点抽成 Q-A 链：
- Q 切要害
- A 四段：结论 / 形式化 / 步骤 / 边界

#### `ljg-invest` — 投资分析

核心判断：项目是否是一台「秩序创造机器」。

---

#### `ljg-relationship` — 关系分析

五层结构诊断 + 精神分析，通过对话引导帮用户"看见"关系真实结构。

#### `ljg-roundtable` — 圆桌讨论

求真导向的结构化多人辩证对话，每轮生成 ASCII 思考框架图。

### 生活与场景

#### `ljg-travel` — 旅行研究

输入城市名，生成深度文化研究文档（org-mode）+ 便携卡片（PNG）。

---

### 工具与系统

#### `ljg-skill-map` — 技能地图

扫描所有已安装技能，渲染可视化总览。

---

#### `ljg-present` — 演讲铸造器（v3.0.0）

基于 org-mode / markdown outline 层级 1:1 视觉化呈现。

**视觉语言**（参考 BIG STUDIOS manifesto 美学）：
- 整篇一个主题色（red / black / yellow）
- left-aligned 舞台美学，超大字号自然撑屏
- 单字 70vmin、长句 11vmin，多行错位
- 关键词自动换色

**核心哲学**：Outline 是真理。Skill 是渲染器。不动内容是一条铁律——标题不改字、段落不改字、列表项不改字、顺序不重排。

---

#### `ljg-push` — 推送引擎

把本地 `~/.claude/skills/ljg-*` 一键同步到 GitHub repo（master + md 双分支）。

## 延伸思考

### 1. 为什么这套技能集值得关注？

当前市面上的 AI 提示词资源大多停留在"功能罗列"层面——告诉你"这个 prompt 可以写文章、那个 prompt 可以做翻译"。李继刚的技能集之所以获得 4.2k Stars，是因为它回答了一个更深层的问题：**一个长期在一线使用 AI 的人，会如何把自己的思维方式编码成可复用的工具？**

每个技能的 SKILL.md 都不是"使用说明"，而是"认知手册"——里面包含了这个技能背后的思考姿态、语言纪律、品味准则。读这些文件本身，就是一次高质量的方法论学习。

### 2. 对 Hermes Agent / 其他 AI 工具的启示

虽然这套技能集是为 Claude Code 的 `.claude/skills/` 架构设计的，但其设计理念完全可以迁移到任何支持自定义指令或 Skill 系统的 AI 工具（如 Cursor Rules、Windsurf Rules、OpenAI Custom Instructions、以及 Hermes Agent 的 Skill 系统）。

核心迁移点：
- **从"功能 prompt"转向"认知框架"**：不要写"帮我总结文章"，而是写"伴读是脚手架，最终要拆——读者被激活才算有效"
- **格式即纪律**：为每个技能强制输出格式（org-mode / Markdown）和存储位置，确保思考成果可被长期积累
- **品味底线**：像 `ljg-card` 中明确列出"反 AI 生成痕迹"的禁忌清单，为自己的输出建立质量护栏

### 3. 如何学习这套技能集？

建议路径：
1. **先读 README**：了解全貌和安装方式（5 分钟）
2. **精读 2–3 个最感兴趣的 SKILL.md**：感受其"认知姿态"而非仅关注功能（30 分钟）
3. **安装并试用一个技能**：体验从输入到输出的完整流程（15 分钟）
4. **模仿写一个自己的技能**：用自己的方法论替换李继刚的框架，输出格式保持不变（60 分钟）
