## 简介

OpenAI Codex 是一个能够直接控制用户电脑的 AI 编程助手。通过启用 Computer Use 功能，Codex 可以像真人一样查看屏幕、操作鼠标和键盘，完成复杂的自动化任务。本教程整理了 @0xTodd 分享的 Mac 设置指南，帮助你快速开启这一强大功能。

---

## 设置步骤

### 前置条件

- 一台独立的 Mac 电脑（建议不存放敏感数据）
- OpenAI 账户（ChatGPT Plus 会员，$20/月）

### 步骤 0：登录 OpenAI 账户

确保你的 OpenAI 账户已订阅 ChatGPT Plus（$20/月会员）。

### 步骤 1：安装 Computer Use 功能

1. 打开 Codex 应用
2. 进入**设置**
3. 找到并安装 **Computer Use** 功能

### 步骤 2：授权系统权限

为了让 Codex 能够控制你的 Mac，需要授予以下两项关键权限：

| 权限类型 | 用途说明 |
|---------|---------|
| **屏幕录制** | 让 Codex 能够"看到"你的屏幕内容 |
| **辅助功能** | 让 Codex 能够控制鼠标和键盘操作 |

**授权路径**：
```
系统设置 → 隐私与安全 → 屏幕录制/辅助功能 → 勾选 Codex
```

## 安全建议

⚠️ **重要提示**：

由于 Codex 拥有完整的电脑控制权，建议仅在以下场景使用：
- **独立的 Mac 设备**（不存放敏感个人/工作数据）
- **测试环境**（用于尝试自动化任务）
- **虚拟机或隔离环境**（如果可能）

**避免在以下设备使用**：
- 存有重要工作文档的生产力电脑
- 有个人银行/金融信息的设备
- 包含敏感隐私数据的主机
