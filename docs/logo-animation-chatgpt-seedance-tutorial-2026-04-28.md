## 简介

本教程介绍如何结合使用 ChatGPT Images 2.0 和 Seedance 2.0 两款 AI 工具，创建专业级的 Logo 动画。核心思路是利用 Images 2.0 生成详细的动画分镜表（Animation Sheet），然后将其作为参考输入 Seedance 2.0 生成最终的视频动画。

---

## 核心工作流程

### 第一步：使用 ChatGPT Images 2.0 创建动画分镜表

**什么是动画分镜表？**

动画分镜表是一个详细的故事板（Storyboard），展示 Logo 应该如何出现、移动和变形。它可以包含：
- 动画时间轴（每个阶段持续多久）
- 运动路径和变形指导
- 视觉风格参考
- 构图和布局建议

**入门提示词模板：**

```
Create an animation sheet for slick logo animation for a company called NEO. 
The logo is minimalist glassmorphic leaf. 
The sheet should show clearly storyboard with animation lines for a slick animation, 
this can be complex.
```

**关键技巧：**
- 在第一次迭代时，确保 AI 理解正确的视觉风格
- 可以上传参考图片帮助 AI 理解你的需求
- 继续与 ChatGPT Images 2.0 对话，进行必要的调整，直到满意为止

---

### 第二步：使用 Seedance 2.0 生成视频

**操作流程：**

1. 将第一步生成的动画分镜表作为参考图片上传到 Seedance 2.0
2. 输入与分镜表匹配的提示词
3. 确保视频的时间长度与动画分镜表一致

**提示词示例：**

```
Create the logo animation as described in the reference image for the NEO product logo. 
Follow the reference exactly.
```

**关键要点：**
- 关键是确保视频的时间与动画分镜表匹配
- 在本案例中，动画时长为 8 秒
- Seedance 2.0 会参考分镜表中的视觉指导生成视频

## 优化技巧与建议

### 1. 明确动画指导原则

确保动画分镜表清晰地展示元素应该如何移动或变形。包括：
- 运动方向（从左到右、从上到下等）
- 变形过程（形状如何变化）
- 时间分配（每个阶段占多少秒）

### 2. 迭代优化

在生成视频之前，可以多次与 ChatGPT Images 2.0 对话调整分镜表：
- 调整动画节奏
- 修改视觉元素
- 优化过渡效果
- 简化或复杂化特定部分

### 3. 优化案例参考

以下是一个真实的优化过程：

**原始问题：**
- 动画总时长约 50 秒（过长）
- 故事板结构复杂
- 背景对比度不足

**优化方案：**
- 将总时长缩减至约 8 秒（紧凑的 Logo 动画）
- 简化故事板结构（减少步骤，流程更清晰）
- 切换为深色背景（确保对比度和可读性）
- 添加专门的分解部分，明确展示形状变形过程
- 优化动画流程，添加清晰的 Orb 效果

## 快速参考

### 标准工作流程

1. **构思阶段**
   - 明确 Logo 风格和品牌调性
   - 确定动画时长（建议 5-10 秒）
   - 准备参考图片（可选但推荐）

2. **分镜表制作**（ChatGPT Images 2.0）
   ```
   Create an animation sheet for [动画风格] logo animation for [公司名称].
   The logo is [描述 Logo 风格].
   The sheet should show clearly storyboard with animation lines for a slick animation.
   ```

3. **迭代优化**
   - 检查视觉风格是否正确
   - 调整时间分配
   - 优化动画流程

4. **视频生成**（Seedance 2.0）
   - 上传分镜表
   - 输入匹配提示词
   - 设置正确时长
   - 生成并下载

### 常见问题

**Q: 动画分镜表需要多详细？**
A: 越详细越好。可以包含具体的时间分配、运动路径、变形指导等。Seedance 2.0 会参考这些信息生成视频。

**Q: 可以调整生成后的视频吗？**
A: 建议先在 ChatGPT Images 2.0 中迭代优化分镜表，满意后再生成视频。如需调整，可以修改分镜表重新生成。

**Q: 适合什么样的 Logo？**
A: 适用于各种风格的 Logo，特别是极简主义、几何图形类的 Logo 效果最好。
