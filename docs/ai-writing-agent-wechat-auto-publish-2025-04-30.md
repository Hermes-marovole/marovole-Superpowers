## 简介

这是一个将 **AI Writing Agent**（多平台自动化写作助手）与 **微信公众号自动发布** 打通的完整工作流解决方案。

借助 @dotey 开发的 `baoyu-post-to-wechat` skill，文章撰写完成后只需一行命令即可直接发布到公众号后台，真正实现从写作到发布的全自动化。

---

## 核心痛点

**传统公众号发布流程的问题：**

1. **编辑器体验差** — 微信公众号后台编辑器操作繁琐、功能有限
2. **多平台切换** — 需要在写作工具和公众号后台之间反复切换
3. **格式兼容** — 从外部编辑器复制到公众号经常丢失格式
4. **人工发布** — 每次发布都需要手动登录、粘贴、排版、预览

---

## 解决方案架构

### 核心组件

| 组件 | 角色 | 说明 |
|------|------|------|
| **AI Writing Agent** | 写作引擎 | 多平台自动化写作助手，负责内容生成 |
| **baoyu-post-to-wechat** | 发布桥梁 | 由 @dotey 开发的 skill，打通公众号 API |
| **Hermes Agent** | 执行层 | 自动执行命令，无需人工干预 |

### 工作流程

```
内容创作 → AI Writing Agent
    ↓
命令触发 → Hermes Agent 自动执行
    ↓
格式转换 → baoyu-post-to-wechat skill
    ↓
自动发布 → 微信公众号后台
```

---

## 关键技术

### baoyu-post-to-wechat skill

这是整个工作流的核心桥梁，它解决了：

- **公众号 API 对接** — 绕过官方复杂接口，实现程序化发布
- **格式自动适配** — Markdown/HTML 自动转换为公众号兼容格式
- **图片处理** — 自动上传图片到公众号素材库并替换链接
- **样式保留** — 标题、引用、代码块等样式完整保留

### 一行命令发布

文章完成后，通过简单的命令参数即可触发发布：

```bash
# 示例命令结构（推测）
hermes-agent --skill baoyu-post-to-wechat --article "文章路径" --title "标题"
```

> 💡 **关键特性**：命令的执行也可以由 Agent 自动完成，实现完全无人干预的发布流程。
