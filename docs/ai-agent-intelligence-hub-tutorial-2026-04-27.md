## 一、系统设计：三行说清楚

**核心原理：**

```
Grok 定时任务（每天 8:00） → 监控 X 关键词/账号/话题/List → 结果发送到 ClawEmail 专属邮箱
                                                                         ↓
                              ClawEmail Agent 接收、提炼、格式化、驱动本地 Agent 执行
                                                                         ↓
                                    每天早上，一封情报简报进你的主邮箱
```

**角色分工：**
- **Grok** = 眼睛：负责在 X 上盯着，原生搜索能力极强
- **ClawEmail** = 大脑：负责把原始信息变成有用的东西
- **本地 Agent** = 双手：执行内容生成、邮件处理等任务

> 你每天早上喝咖啡的时候，简报已经在收件箱等着了。

## 二、专属邮箱：AI Agent 的 7×24 小时全域情报中枢

### 核心价值

为 Agent 配置专属邮箱的第一个核心价值，是把它打造成**全自动的情报处理中心**。

以前靠自己刷 X，信息茧房、无效噪音、FOMO 情绪干扰极大。现在，Agent 有了自己的「耳朵」，可以 7×24 小时不间断地监听世界，定向对接 X 平台，完成全维度信息的实时监控与筛选。

### 5 个独立监控任务拆解

为了让系统更解耦、更细致、更可维护，建议拆成 5 个独立 Grok Tasks（每天早上 7:30 并行运行，互不干扰）：

| 任务 | 监控目标 | 具体维度 |
|------|----------|----------|
| **Task 1** | 个人存在感监控 | 抓取 @提及、引用、爆帖信号，内容被转发的异常互动数据 |
| **Task 2** | AI 独立开发 & 交易赛道热议 | 监控 ClawEmail、zCloak、AI Agent、贾维斯式 Agent 等关键词，捕捉新兴工具和爆款玩法 |
| **Task 3** | 竞品 & 同行动态 | 关注/互动列表中，粉丝数 2k+ 且 24h 内有热度的帖子，分析值得学习或差异化的内容 |
| **Task 4** | 商业机会 & 用户需求 | 抓取商单、合作、融资讨论，以及用户问"有没有工具可以…"的痛点帖 |
| **Task 5** | 内容选题 + 市场情绪 | 分析新兴赛道、热词趋势、舆情风向，预判原创角度 |

**输出格式：**
所有 5 个任务的输出都是**结构化原始情报包**（Markdown 格式），自动通过 Gmail 转发到 ClawEmail 邮箱。

从此，Agent 拥有了一个**永不疲倦、零噪音的全域情报大脑**。

## 三、「邮件即指令」系统：基于邮箱的分布式 AI 能力双向交互

### 核心设计理念

我们并没有止步于单向情报监控，而是进一步搭建了完整的 **「邮件即指令」** 交互体系。

当 Agent 拥有专属独立邮箱后，邮箱就成了你和 Agent 之间**最自然、最可靠的核心交互入口**：

- 你通过邮件下发任务
- Agent 通过邮件响应指令
- 直接调用本地 Agent 服务和代码库
- 实现跨终端的分布式执行

这就是 ClawEmail 最强大的地方——**Email Channel 模式**。

### 完整执行流程

```
1. Grok Tasks 的情报包到达 ClawEmail 子邮箱
              ↓
2. OpenClaw Agent 自动触发处理规则（配置一次即可）
              ↓
3. Agent 读懂上下文 → 决策高价值机会
              ↓
4. 直接调用本地 Claude / OpenClaw 主 Agent 和本地代码库
              ↓
5. 生成完整 X 推文（带话题、图片建议）、长文草稿、回复草稿、行动清单
              ↓
6. 把「执行报告」推送到主邮箱
```

**真正实现了：情报 → 理解 → 执行 → 输出的闭环**

### 真实体验：从「我指挥 AI」到「AI 自己工作」

以前每天要花 1-2 小时刷 X、找选题、写草稿、回复提及。现在：

| 场景 | Agent 自动执行 |
|------|----------------|
| 有人提到我 | 自动生成回复草稿 |
| 发现新热词/爆款玩法 | 直接写成个人风格的推文 |
| 用户痛点出现 | 立刻生成产品灵感或内容选题 |

**这才是真正的「Agent 自主协作」。**

## 四、搭建步骤：4 步实操指南

### Step 1：给 AI Agent 注册一个专属邮箱

前往 [ClawEmail](https://claw.email) 创建一个专属邮箱。

**建议命名规范：**
- `mymonitor@claw.163.com` —— 专门收情报，与其他任务邮箱隔离
- `myagent@claw.163.com` —— 综合任务处理

**注意：** 创建邮箱时可以用任意邮箱先登录注册。

### Step 2：在 Grok 创建定时任务

Grok 的定时任务是很多人忽略的功能，它可以：
- 结合 X 原生功能，完美读取 X List、Advanced Search、话题等
- 比第三方工具更实时、更精准

**账户限制：**
- 免费用户：只能设置 2 个定时任务
- Premium+：每天多个任务都没问题

**操作建议：** 根据账户情况，先设定每天自动跑一个 Prompt 任务，结果发送到指定邮箱。

**Prompt 按监控维度编写**（详见第五章完整模板）。

### Step 3：设置 Gmail 自动转发

设置过滤器，把来自 Grok 的邮件自动转发到 ClawEmail。

**原因：** Grok 的定时任务只支持 X 绑定的邮箱接收，所以需要额外设置将 Gmail 收到的邮件转发至注册好的 ClawEmail。

**操作路径：** Gmail → 设置 → 过滤器和屏蔽的地址 → 创建过滤器

### Step 4：配置 ClawEmail Agent 处理规则

#### 4.1 绑定邮箱到 OpenClaw

将 Step 1 创建的邮箱绑定到你的 OpenClaw 中，直接粘贴命令行给 OpenClaw 执行即可。

#### 4.2 配置基础处理规则

在 OpenClaw 会话窗口里直接说：

> "帮我配置一个规则：mymonitor@claw.163.com 收到邮件后，提炼成日报格式发到我的主邮箱，每天早上 8:30。"

它会自动搭好基础框架。

#### 4.3 配置高级「邮件即指令」规则

添加以下规则给你的 OpenClaw：

```
你现在是我的专属「贾维斯情报执行官」（ClawEmail + OpenClaw 主 Agent）。

收到主题包含"原始情报包"的邮件后，严格执行以下流程：

1. 解析 Grok 情报包的所有维度（个人提及、赛道热议、竞品、机会、趋势）

2. 决策：
   - 高价值内容（适合我风格的选题、商单机会、用户痛点等）→ 进入「自动创作模式」
   - 普通提及 → 生成回复草稿
   - 其他 → 生成精炼早报

3. 「自动创作模式」具体操作（最重要）：
   - 使用我的文风记忆（参考之前的系列，轻松、专业、干货+故事感）
   - 调用 Claude（或主 OpenClaw Agent）生成：
     * 完整 X 推文（带话题、图片建议）
     * 或完整文章草稿（带标题、结构、配图提示）
   - 输出格式：
     【自动生成内容】
     - 类型：X推文 / 长文
     - 标题/正文：（完整内容）
     - 建议发布时机：...
     - 行动按钮：我已确认发布 / 需要微调

4. 最终输出：
   - 一封「执行报告」邮件发到我的主邮箱
   - 包含：早报 + 所有草稿 + 回复建议 + 待确认行动项

保持我的语气：专业但像老朋友聊天。只输出最终结果，不要解释过程。
```

**整个系统搭好后，几乎零维护，每天自动跑。**

## 五、Prompt 模板参考

### 模板 A：Grok 情报官 Prompt

```
你是我（@nopinduoduo，多多）的专属 X 情报官。

每天使用 X 搜索工具（关键词搜索 + 语义搜索 + 用户/列表搜索），分析过去 24 小时的数据。

只输出**结构化原始情报包**，供我的 ClawEmail Agent 二次处理。不要输出任何最终结论或美化后的早报。

### 核心监控维度（优先级从高到低）：

1. 个人存在感（@nopinduoduo 或 "多多" 的所有提及、引用、爆帖信号）
2. AI 独立开发 & 交易赛道热议（AI Agent、ClawEmail、AI 交易、贾维斯式 Agent 等）
3. 竞品 & 同行动态（我的关注/互动列表中，粉丝数在5k以上的，且24h内，内容有热度的帖子）
4. 商业机会 & 用户需求（商单、合作、融资、用户痛点求助帖）
5. 内容选题情报（适合我「给AI钱包→身份证→耳朵」系列的原创角度）

### 输出格式（严格使用以下 Markdown 结构）：

**📅 原始情报包 - YYYY-MM-DD**

**🔍 个人提及**
- [帖1] 作者 @xxx
  • 摘要：...
  • 链接：https://x.com/...
  • 信号强度：高/中/低
  • 建议行动：回复/转发/观察

**🌐 赛道热议**
- [洞见1] 关键词/话题
  • 核心内容
  • 链接
  • 我的初步点评（1句）

**👥 竞品动态**
- [动态1] ...

**💡 潜在机会 & 用户痛点**
- [机会1] ...

**📈 趋势信号**（一句话总结今天风向）

**🚨 需要 Agent 立即处理的条目**（高优先级，标注 P0/P1）

要求：
- 所有链接保持完整
- 语言保持中性、专业、客观（不要带个人语气）
- 总长度控制在 1200 字以内
- 只用中文输出
- 这是给 ClawEmail Agent 的"指令邮件"，请严格结构化
```

## 核心洞察

> "做一次作品是魔法，做一条生产线是工程。"

Grok 发出来的原始内容，是给 LLM 看的格式，不是给人看的——结构乱、信息密度高、没有优先级排序。你直接收到，反而会觉得"这怎么比我自己刷 X 还费劲"。

**ClawEmail 在中间做了一件很关键的事：把 AI 的输出，变成人能直接用的东西。**

这就是它和普通邮件转发的区别——它有 **Agent 处理层**，你可以定义"我要什么样的输出"，而不只是被动接收。

这是贾维斯进化中很重要的一步：它不再只是一个"接任务-执行任务"的工具，它开始有了**主动感知外部世界的能力**。
