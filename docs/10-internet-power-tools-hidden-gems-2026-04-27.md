## 详细内容

### 1. Shodan

**来源**：@NFTCPS  
**链接**：https://shodan.io  
**类型**：网络安全/搜索引擎

#### 核心功能
堪称黑客级搜索引擎，能搜到全球暴露在公网的摄像头、服务器、路由器。你以为你家监控很安全？上去搜一下再说。

#### 主要用途
- 搜索暴露的物联网设备（摄像头、打印机、路由器）
- 发现服务器漏洞和配置错误
- 网络安全研究和渗透测试
- 了解互联网基础设施分布

#### 适用场景
| 场景 | 说明 |
|------|------|
| 安全审计 | 检查自己的设备是否意外暴露 |
| 漏洞研究 | 发现全球范围内的配置错误 |
| 学术研究 | 物联网安全态势分析 |
| 威胁情报 | 追踪特定恶意基础设施 |

#### 使用提示
- 免费账户有搜索限制
- 高级功能需要付费订阅
- 仅用于合法安全研究

### 2. Archive.org (Wayback Machine)

**来源**：@NFTCPS  
**链接**：https://archive.org  
**类型**：信息存档/互联网历史

#### 核心功能

#### 主要用途
- 查看网站历史版本
- 绕过付费墙阅读内容
- 恢复已删除的网页内容
- 研究互联网历史变迁

#### 适用场景
| 场景 | 说明 |
|------|------|
| 绕过付费墙 | 阅读被付费墙阻挡的新闻文章 |
| 内容恢复 | 找回已删除的网页或博客 |
| 竞品追踪 | 查看竞争对手网站历史变更 |

```
1. 访问 https://web.archive.org/
```

### 10. Explainshell

**来源**：@NFTCPS  
**链接**：https://explainshell.com  
**类型**：开发工具/学习辅助

#### 核心功能
不懂Linux命令？粘进去，每一段代码逐字给你翻译解释。程序员新手救命工具。

#### 主要用途
- Linux命令逐段解释
- 学习命令行参数含义
- 理解复杂命令结构
- 新手入门教学

#### 支持内容
- Bash命令
- 命令行参数详解
- 管道和重定向解释
- 常用工具说明（grep, awk, sed等）

#### 使用示例
```
输入: ls -la | grep ".txt" | wc -l

解释:
- ls -la: 列出当前目录所有文件（包括隐藏文件），显示详细信息
- | (管道): 将前一个命令的输出传递给下一个命令
- grep ".txt": 筛选包含".txt"的行
- | (管道): 再次传递
- wc -l: 统计行数（即.txt文件数量）
```

#### 适用人群
- Linux新手
- 运维入门者
- 命令行学习者
- 需要理解他人脚本的人
