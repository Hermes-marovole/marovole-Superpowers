## 什么是 GPT Image 2？

**GPT Image 2**（代号 **"duct-tape"**）是 OpenAI 的下一代图像生成模型，相比前代实现了以下质的飞跃：

| 能力 | 描述 |
|------|------|
| 🎯 **像素级文字渲染** | 中文、英文、日文均达到 native 水准，无错字、无字形扭曲 |
| 🎨 **跨图像素级一致性** | 同一角色、风格、IP 在多张图间保持像素级一致 |
| ⚡ **商用级插画质量** | 插画风格输出无需人工精修，即可直接用于商业场景 |
| 🌈 **真实艺术风格注入** | 不止是"模仿参考图"，而是真正理解并再现艺术风格的灵魂 |
| 🔧 **故事板与产品系列** | 适合故事板、IP 形象、产品系列图等需要多图一致性的场景 |
| 📐 **多语言平面设计** | 社交卡片、Banner、海报一次生图即可完成多语言文字排版 |

## 精选 6 个高频场景

根据 Niko 的 X 帖子推荐，以下是 6 个最高频的使用场景（对应仓库中的 Use Case 分类）：

### 1️⃣ 语录卡片 — 文字精准渲染，中英日都能出

**用途**：制作社交媒体金句卡片、名人名言配图、读书笔记可视化  
**核心优势**：GPT Image 2 的文字渲染能力使中文、英文、日文都能精确呈现，无错别字  
**对应分类**：`text-typography` / `social-media-post`

### 2️⃣ 商业插画 — 商用级质量，不用修图直接发

**用途**：公众号配图、博客插图、品牌营销素材  
**核心优势**：输出质量可直接商用，无需后期精修  
**对应分类**：`illustration` / `product-marketing`

### 3️⃣ 分镜脚本 — 多图角色一致，做内容必存

**用途**：短视频脚本、漫画分镜、故事板制作  
**核心优势**：跨图像一致性确保同一角色在多张图中保持一致  
**对应分类**：`comic-storyboard` / `cinematic-film-still`

### 4️⃣ 多语言海报 — 一次生图，多语言文字一起排好

**用途**：国际化营销海报、多语言社交卡片、活动宣传图  
**核心优势**：一次生成即可同时处理多种语言的排版  
**对应分类**：`poster-flyer` / `infographic-edu-visual`

### 5️⃣ 产品营销图 — 电商主图与广告素材

**用途**：电商产品图、广告 Banner、产品爆炸视图  
**核心优势**：支持产品细节展示和复杂信息图排版  
**对应分类**：`ecommerce-main-image` / `product-marketing`

### 6️⃣ 个人头像 / 虚拟形象 — 社交资料与品牌 IP

**用途**：社交头像、虚拟主播形象、个人品牌视觉  
**核心优势**：支持多种风格（赛博朋克、动漫、写实等）  
**对应分类**：`profile-avatar` / `character`

## Raycast 集成

部分提示词支持使用 [Raycast Snippets](https://raycast.com/help/snippets) 语法的**动态参数**，方便快速迭代：

```
A quote card with "{argument name="quote" default="Stay hungry, stay foolish"}"
by {argument name="author" default="Steve Jobs"}
```

在 Raycast 中使用时，可以动态替换参数，无需每次手动编辑提示词。

## 使用建议

### 快速上手路径

1. **直接浏览网页图库**：访问 https://youmind.com/gpt-image-2-prompts
2. **按场景筛选**：选择你需要的 Use Case 分类
3. **复制提示词**：点击任意提示词卡片，复制完整 Prompt
4. **粘贴到 ChatGPT**：在 ChatGPT 中使用 GPT Image 2 功能生成图片

### 进阶使用

- 使用 Raycast Snippets 实现动态参数替换
- 参考精选提示词的 JSON 结构化写法编写自己的提示词
