## 简介

在 2026 年的求职市场中，AI 正在重塑招聘流程。当 HR 们用 AI 筛选简历时，求职者也需要用 AI 来反击。**Career-Ops** 是一个开源的 AI 驱动求职系统，它不仅帮你批量投递，更重要的是——**帮你筛选出真正值得投入精力的高质量职位**。

作者使用 Career-Ops 刷了 **740+ 职位**、生成 **100+ 份定制简历**，最终拿下了 **Head of Applied AI** 的 offer。项目发布短短几天内就获得了 **41.7k GitHub Stars**。

## 详细功能解析

### 一、智能职位评估系统

Career-Ops 的核心优势不在于"海投"，而在于**高端过滤**。

**评估维度**（10 个加权指标）：
1. 技术栈匹配度
2. 职级与薪资期望对齐度
3. 公司技术成熟度
4. 成长空间评估
5. 团队构成分析
6. 地理位置/远程政策
7. 福利与股权激励
8. 工作-生活平衡指标
9. 面试流程复杂度
10. 总体推荐度

**评分规则**：
- A-F 等级制，低于 4.0（D 级）的职位自动过滤
- 加权算法确保高匹配度职位优先展示

### 二、ATS 优化简历生成

**技术栈**：
- **关键词注入**：AI 分析 JD 提取高频关键词，自动融入简历
- **Space Grotesk 字体**：专业排版，提升可读性
- **Playwright 渲染**：自动生成高质量 PDF

**输出效果**：
- 每份简历针对特定职位定制
- 通过 ATS（申请者追踪系统）筛选的概率大幅提升
- 格式统一、专业度高

### 三、批量职位扫描

**支持平台**（45+ 个）：

| 类型 | 代表平台 |
|------|----------|
| AI/ML 顶级公司 | Anthropic、OpenAI、ElevenLabs、Cohere、Runway |
| 自动化平台 | n8n、Zapier、Make |
| 开发者工具 | Vercel、Supabase、Linear、Figma |
| 创业公司 | YC 系、AI-native startups |
| 传统企业转型 | 各大科技巨头的 AI 部门 |

**工作流**：
1. 设置目标公司清单
2. Career-Ops 自动扫描所有平台的最新职位
3. 批量评估并生成报告
4. 一键导出高匹配度职位

### 四、六大深度报告

| 报告类型 | 内容 | 用途 |
|----------|------|------|
| **匹配分析报告** | JD vs 简历的详细对比 | 了解差距、针对性补强 |
| **薪酬调研报告** | 市场薪酬区间、谈判空间 | 谈薪时有数据支撑 |
| **STAR 故事库** | 过往经历的结构化整理 | 面试时快速调用案例 |
| **薪资谈判脚本** | 基于市场数据的谈判话术 | 争取更好 package |
| **公司背景分析** | 技术栈、融资阶段、团队 | 面试前知己知彼 |
| **面试准备清单** | 针对性问题预测与答案 | 面试表现更从容 |

**持续学习机制**：
- 每次申请后记录反馈
- STAR 故事库越用越丰富
- 形成个人求职知识资产

### 六、Human-in-the-Loop 设计哲学

**核心理念**：AI 是助手，不是替代者。

**工作流**：
1. AI 分析职位、生成建议、准备材料
2. 人类审查 AI 的分析结果
3. 人类做出最终决策（申请/跳过/待定）
4. AI 记录反馈，持续优化推荐算法

**优势**：
- 保持求职者的主体性和判断力
- 避免盲目依赖 AI 导致的错误决策
- 确保每份申请都经过人工确认

### 七、多模型 CLI 支持

**支持的 AI 模型/工具**：
- **Claude Code**（Anthropic）
- **Gemini CLI**（Google）
- **OpenCode**（开源替代方案）

**灵活性**：
- 可按需选择模型
- 不同任务可用不同模型（如简历生成用 Claude，职位扫描用 Gemini）
- 支持本地模型（通过 Ollama 等）

## 快速上手

### 安装步骤

```bash
# 1. 克隆仓库
git clone https://github.com/author/career-ops.git
cd career-ops

# 2. 安装依赖
npm install

# 3. 准备你的简历
# 将你的简历保存为 cv.md，放入项目根目录

# 4. 启动交互式 CLI
career-ops

# 5. 粘贴目标 JD，让系统全自动跑管道
# 或导入职位列表进行批量评估
```

### 配置说明

**必需配置**：
1. **API Keys**：设置 Claude/Gemini/OpenAI API Key
2. **简历文件**：`cv.md` 放在项目根目录
3. **偏好设置**：编辑 `config.json` 设置目标公司、薪资期望、地点偏好等

**可选配置**：
- 自定义评估权重
- 设置自动化扫描时间
- 配置邮件通知

## 与"海投工具"的本质区别

| 维度 | 传统海投工具 | Career-Ops |
|------|-------------|-----------|
| **核心策略** | 数量优先，广撒网 | 质量优先，精准匹配 |
| **评估机制** | 无 | 10 维度加权评分 |
| **简历定制** | 千篇一律 | 每份简历针对 JD 定制 |
| **决策支持** | 无 | 6 大深度报告辅助决策 |
| **人机协作** | 全自动（风险高） | Human-in-the-Loop |
| **长期价值** | 一次性工具 | 持续积累个人求职知识库 |

**核心差异**：
Career-Ops 不是帮你"乱枪打鸟"，而是帮你**把有限的精力集中在真正值得的那几个 offer 上**。

## 快速参考

### 常用命令

```bash
# 启动交互式界面
career-ops

# 批量评估职位列表
career-ops --batch jobs.json

# 生成单份定制简历
career-ops --resume --jd "职位描述文本"

# 扫描指定平台
career-ops --scan --platforms "anthropic,openai,elevenlabs"

# 导出报告
career-ops --report --format pdf
```

## 总结

Career-Ops 代表了 2026 年求职工具的新范式：

1. **AI 对抗 AI**：当招聘方用 AI 筛选简历时，求职者也需要 AI 来优化策略
2. **质量 > 数量**：不是海投，而是精准匹配，把精力放在真正值得的机会上
3. **人机协作**：AI 负责分析、人类负责决策，保持主体性
4. **持续积累**：STAR 故事库等机制让求职经验变成可复用的知识资产

**适用人群**：AI 工程师、产品经理、转行 AI 者、资深从业者——在 2026 年的卷王市场里，这套系统非常适合。
