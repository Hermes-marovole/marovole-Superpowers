## 结构化 Prompt 格式

该仓库中有大量使用 **JSON 格式**的 Prompt，这是 GPT Image 2 支持的结构化输入方式。

### JSON 结构示例

```json
{
  "type": "产品类型",
  "subject": {
    "product": "产品描述",
    "brand": "品牌名"
  },
  "layout": {
    "grid": { "rows": 3, "columns": 3 },
    "sections": [ ... ]
  },
  "style": {
    "photography": "摄影风格",
    "lighting": "光线类型",
    "color_palette": ["颜色1", "颜色2"],
    "mood": "情绪基调"
  }
}
```

### Raycast 动态参数语法

部分 Prompt 支持动态替换参数（配合 Raycast Snippets）：

```
{argument name="product name" default="Niacinamide 10% Face Serum"}
{argument name="brand name" default="LUMIÈRE"}
{argument name="headline text" default="Effortless shine."}
```

## 值得吸收的新模板类型

以下是在我们已有 `gpt-image-2-prompts` skill（已涵盖博物馆图鉴、书法、叙事海报、老照片修复、金句封面、日签）基础上，值得新增的模板方向：

### 1. 城市美食地图（手绘水彩信息图）

结构：主视觉地图 + 编号地点标注 + 图例 + 装饰边框
适合：旅行攻略、城市指南、美食推荐

### 2. 电商直播界面（UI Mockup）

结构：主播肖像 + UI 覆盖层（聊天、礼物、商品卡、排行榜）
适合：产品 Demo、直播运营、界面设计方案

### 3. 产品多视角拼图（3×3/网格布局）

结构：同一产品从多个角度拍摄，网格排列
适合：电商详情页、产品手册、品牌展示

### 4. Mixed Style 混合风格

Irasutoya × 信息密集型幻灯片风格
适合：知识科普、教育内容（Neumina 场景很有潜力）
