## 简介

这是一个**升级版**的 GPT 提示词方案，专门针对**简单句子结构**优化，能在 **20 秒内**将普通文字转换成**抓人眼球的金句封面图**。

核心亮点：
- ✅ 适合短句/金句类内容
- ✅ 智能语义配色（不再五颜六色乱配）
- ✅ 高桥流排版思路（一页一重点）
- ✅ 有呼吸感的视觉呈现

告别密密麻麻、配色混乱的"小学生手抄报"风格。

## 使用方法

### 步骤 1：复制提示词
复制上方完整提示词到 GPT（支持 GPT-4o、GPT-4o-image 等带图像生成能力的模型）。

### 步骤 2：替换金句
将提示词最后三行反引号内的示例文本：
```
太阳就站在黑夜的门口
```
替换为你想呈现的金句或短文案。

### 步骤 3：生成封面
发送给 GPT，等待 20 秒左右即可获得一张高质感封面图。

## 设计思路解析

| 设计维度 | 实现方式 |
|---------|---------|
| **配色逻辑** | GPT 智能理解文本语义，自动匹配适合的配色方案 |
| **排版风格** | 借鉴高桥流（Takahashi Method）—— 一页一关键词，字撑满屏 |
| **信息密度** | 极简主义，只保留核心文案，无冗余元素 |
| **视觉呼吸感** | 合理的留白与字间距，避免压迫感 |
| **字体呈现** | 超大字号，直击视觉焦点 |

## 进阶技巧

### 1. 长文本优化
如果你输入的是大段文本，GPT 会**智能提炼核心观点**，而不是机械照搬。这意味着：
- 输入一段感悟 → 输出一句金句
- 输入一篇文章摘要 → 输出一个核心洞察

### 2. 配色方向引导
如需指定配色风格，可在金句后追加风格关键词：
- `莫兰迪治愈系`
- `高级黑白灰`
- `暖橙活力感`
- `冷蓝科技感`

### 3. 批量生成
将多条金句整理成列表，让 GPT 批量生成统一风格的封面系列，适合：
- 7 天打卡海报
- 系列金句日历
- 课程章节封面
