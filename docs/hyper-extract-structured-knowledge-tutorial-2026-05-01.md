## 简介

读论文、研报、合同，最痛苦的从来不是读，而是读完以后要把海量信息整理成结构化的知识。

**Hyper-Extract** 直接把这个痛点干掉！用 LLM 把任意非结构化文本自动提取成知识图谱、时间线、关系网络等结构化内容。

---

## 核心亮点

### 🔹 8 种输出格式
列表、模型、图谱、超图、时空图……随便你要哪种结构化形式。

### 🔹 10+ 种顶级提取引擎
覆盖当前主流 RAG 技术：
- **GraphRAG**
- **LightRAG**
- **Hyper-RAG**
- **KG-Gen**
- 以及其他更多引擎

### 🔹 80+ 个现成 YAML 模板
覆盖多个垂直领域，零代码直接用：
- 金融
- 法律
- 医疗
- 中医
- 工业
- ……更多专业领域

### 🔹 增量更新机制
新文档自动扩展已有知识库，不用每次从头跑，大幅提升效率。

## 快速开始

### 安装

```bash
uv tool install hyperextract
```

### 基本用法

**1. 解析文档**

```bash
he parse 你的文档.md -t 模板名 -o 输出目录
```

**2. 查询知识库**

```bash
he search 输出目录 "你的问题"
```
