### 推文2：Biohacker + 数据

```
连续30天每天监测晨起心率变异率（HRV）后，我发现：

喝咖啡的时机，比喝多少更重要。

数据：
• 起床后立即喝 → HRV 平均下降12%
• 起床后90分钟喝 → HRV 几乎无变化
• 下午2点后喝 → 当晚深睡减少18%

原理：皮质醇自然峰值在醒后75-90分钟，
这时候叠加咖啡因，效果叠加而不是对抗。

一个小调整，同样的摄入量，不同的身体反应。
```
