**Day 12 — Biohacking 首条**：
```
连续 30 天每天监测晨起 HRV 后，我发现：

喝咖啡的时机，比喝多少更重要。

数据：
• 起床后立即喝 → HRV 下降 12%
• 起床后 90 分钟喝 → HRV 几乎无变化
• 下午 2 点后喝 → 深睡减少 18%

原理：皮质醇峰值在醒后 75-90 分钟，
此时叠加咖啡因 = 效果叠加。

一个小调整，同样的摄入量，
不同的身体反应。
```

```
VibeCoding 6 个月后，我的 3 个认知变化：

1. 以为是提速编码，其实是提速想清楚需求
   ——AI 写得快，但如果需求不对，只是更快地写出垃圾

2. 以为是减少工作，其实是重新分配注意力

3. 以为是个人超能力，其实是团队协作方式的重构
   ——一个人用 Cursor 写得快，
      但如何让 5 个人用 AI 协作更是问题

这不是反 AI，是用了 6 个月后的真实反思。
```
