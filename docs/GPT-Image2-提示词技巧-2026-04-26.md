## 五、日签设计字体逻辑

### 设计三要素
一张优秀的日签图必须同时成立三件事：

1. **画面本身好看**
   - 有氛围、有质感、有设计感

2. **文案本身成熟**
   - 有记忆点、有解读空间
   - 不幼稚、不低龄、不像廉价鸡汤

3. **信息本身有内容**
   - 尤其要有干货价值

### 字体逻辑层次

#### 一、主标题字体逻辑
- 主标题是一句**最核心的日签文案**
- 是整张图**最重要的文字**
- 必须清晰可读，具有系列主视觉作用
- 标题与图片之间要有良好的视觉平衡
- 不能简单粗暴地在文字后面压一整块黑色遮罩

#### 二、日期模块字体逻辑
- 日期不是附属信息
- 而是画面中的**第二层视觉锚点**

#### 三、副文案字体逻辑
- 补充说明和延展信息
- 字体层级次于主标题和日期

### 信息结构原则
- 像**好的slides**一样
- **一眼看懂结构**
- **细看理解细节**

### 布局选择逻辑
根据内容自动选择最佳视觉布局：
- **流程** → 箭头串联
- **对比** → 左右分栏
- **循环** → 环形
- **组成** → 并列卡片
- **层级** → 嵌套结构

## 技巧总结

### 提示词工程核心原则

1. **角色定义明确**
   - 使用"World-class"、"Professional"等限定词提升输出质量
   - 复合型角色（如"插画师+架构师"）可获得更专业的结果

2. **结构化提示词**
   - 使用标准格式：Role + Task + Requirements
   - 分层描述：整体风格 → 局部细节 → 技术参数

3. **可替换性设计**
   - 将主题/内容作为变量，提示词框架固定
   - 便于批量生成系列内容

4. **场景化应用**
   - 针对具体平台（小红书、抖音）优化提示词
   - 考虑目标受众的使用场景和需求

### 运营技巧要点

1. **快速风格复刻**
   - 利用AI分析爆款账号的视觉DNA
   - 提取可复用的提示词元素

2. **商业化路径**
   - 老照片修复可直接接单变现
   - 信息图制作可服务知识付费领域

3. **内容系统化**
   - 建立提示词库，分类管理
   - 长版+短版双版本策略，适配不同需求
