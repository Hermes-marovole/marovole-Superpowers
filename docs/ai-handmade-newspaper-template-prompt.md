## 📖 简介

这是一套在小红书卖出**上千单**的爆款手抄报模板方案，由 AI 独立开发者 **koffuxu（可夫小子）** 原创开发并开源分享。

核心亮点：
- **一套图 = 3 种用途**：幼儿园/小学手抄报 + 涂色素材（家长刚需）+ 教育类内容素材（老师/机构刚需）

## 🎯 效果展示

这套模板生成的图片采用独特的 **"上半彩色 + 下半黑白线稿"** 结构：

| 上半部分 | 下半部分 |
|---------|---------|
| 彩色完整图，可直接作为手抄报成品 | 黑白线稿，适合儿童涂色 |
| 用于展示、印刷、成品提交 | 家长刚需的涂色素材 |

**示例主题**：
- 「乌鸦喝水」
- 「狐狸与葡萄」
- 「狼来了」
- 任何寓言/成语故事都可替换生成

## 🛠️ 完整提示词（Prompt）

```yaml
# ===== 基础设定 =====
style: 儿童绘本风 + 手抄报模板 + 可涂色线稿
layout: 竖版 9:16
composition: 上半彩色 + 下半黑白线稿（完全一致构图）
quality: 高清、干净、适合打印、边缘清晰

# ===== 标题区 =====
title:
  text: "{成语或寓言名称}"
  style: 可爱卡通手写字
  layout: 顶部居中
  decoration:
    - 每个字放入彩色圆形气泡
    - 颜色：蓝、紫、绿、黄（可循环）
    - 高饱和但柔和

# ===== 场景设定（核心可替换）=====
scene:
  left_character:
    role: "{角色1}"
    action: "{动作1}"
    expression: "{表情1}"
    outfit: "{服装（可选）}"
  right_character:
    role: "{角色2}"
    action: "{动作2}"
    expression: "{表情2}"
  environment:
    elements:
      - 树
      - 草地
      - 弯曲道路/河流/场景关键路径
    style: 简洁背景 + 儿童友好

# ===== 构图细节 =====
composition_details:
  - 左侧主角色，右侧次角色（形成故事对比）
  - 中间有路径/视觉引导（路/水流/藤蔓等）
  - 右侧留白区域用于书写（横线）
  - 画面平衡、留白充足

# ===== 视觉风格 =====
visual_style:
  line: 圆润、粗细均匀、清晰描边
  color: 明亮、柔和、低对比舒适
  shading: 轻微渐变，儿童绘本质感
  mood: 童趣、轻松、教育意义

# ===== 边框 =====
border:
  style: 蓝色描边边框
  thickness: 中等
  look: 干净、规整

# ===== 下半部分（关键结构）=====
bottom_section:
  type: 黑白线稿
  requirement:
    - 与上半部分构图完全一致
    - 去除颜色，仅保留轮廓线
    - 适合儿童涂色
    - 线条清晰，不要阴影

# ===== 输出要求 =====
output:
  - 高分辨率
  - 无水印
  - 无多余文字
  - 中文文字正确
```

## 📝 使用方法

### 步骤 1：选择 AI 图像生成工具

推荐使用以下工具：
- **ChatGPT Image (GPT-4o)** - 效果最佳，理解结构化 Prompt 能力强
- **Midjourney** - 适合艺术风格调整
- **DALL-E 3** - 中文理解好
- **Stable Diffusion** - 本地部署，可精细调整
- **即梦、可灵** - 国产工具，中文支持好

### 步骤 2：替换主题变量

将 Prompt 中的变量替换为你的目标主题：

| 变量 | 示例值（乌鸦喝水） | 示例值（狐狸与葡萄） |
|------|-------------------|---------------------|
| `{成语或寓言名称}` | 乌鸦喝水 | 狐狸与葡萄 |
| `{角色1}` | 乌鸦 | 狐狸 |
| `{动作1}` | 衔着石子投入瓶中 | 跳跃试图摘葡萄 |
| `{表情1}` | 聪明、专注 | 渴望、期待 |
| `{角色2}` | 水瓶/水 | 葡萄藤 |
| `{动作2}` | 水位上升 | 垂挂的葡萄串 |
| `{表情2}` | - | - |

### 步骤 3：生成与调整

1. 将完整 Prompt 粘贴到 AI 工具
2. 生成后检查上下两部分构图是否一致
3. 如需调整，可修改表情、动作、配色等细节
4. 保存高分辨率版本用于打印

## 🎨 设计要点解析

### 为什么这种结构能卖爆？

1. **上半彩色图**
   - 可直接交作业（成品）
   - 视觉吸引力强，家长一眼看到效果
   - 适合展示、印刷

2. **下半黑白线稿**
   - 家长刚需（孩子需要涂色作业）
   - 可重复使用（打印多次涂色）
   - 培养动手能力，符合教育理念

3. **9:16 竖版**
   - 符合手抄报标准格式
   - 手机浏览友好
   - 打印适配 A4/A3 纸张

4. **右侧留白**
   - 预留书写区域
   - 符合手抄报"图文结合"要求
   - 孩子可以添加自己的文字内容

## ⚠️ 注意事项

1. **版权问题**：生成的图片商用需注意 AI 工具的使用条款
2. **中文显示**：部分 AI 工具对中文文字渲染可能不完美，建议后期用 Canva 添加标题
