## 简介

这是一套让 Claude Code 在夜间自动执行任务的工作流，充分利用未用完的 API Token。核心理念是：让 AI 读取你的个人画像、Obsidian 笔记和待办事项，在你睡觉时自动研究、实践和探索，第二天早晨为你呈现完整的报告和惊喜。

## 核心 Prompt 模板

### 版本一：夜间自动探索模式

```
我马上要睡觉去了，但是我还有大量的 token 没有用完，我希望能最大化的发挥作用，做一些对我有帮助的事情。

现在你读取我的个人画像，我 obsidian 中的文件，读取我近期/很久之前想做未做的事情，去尽情的研究，去实践，去探索吧。

这样，明天早上我醒来之后，给我惊喜，报告，告诉我一切吧。

（btw，不要把我系统搞崩，不要删库，不要执行危险操作）
```

### 版本二：系统飞轮构建模式

```
为我扫描整个电脑，先扫描一些关键目录，然后再对这些磁盘信息进行扫描，跳过一些软件的安装目录，完善我的人物画像，我想为我的系统构建飞轮，请你完整的分析，并为我沉淀下来有价值的信息，根据获取到的信息，为我构建系统飞轮
```

## 核心洞察

> "做一次作品是魔法，做一条生产线是工程"

这套工作流的本质是将 Claude Code 从「对话工具」升级为「夜间自动代理」：

1. **数据驱动的自我认知**：让 AI 基于你的真实数据（Obsidian、文件系统、浏览历史）构建比你自己更准确的「人物画像」

2. **Token 利用最大化**：将原本可能浪费的夜间 Token 转化为实际生产力

3. **ADHDer 友好**：特别适合容易开很多头但难以收尾的人群，AI 能帮你梳理那些「开了头但远远没有做完的事情」

4. **上下文优势**：Claude Code 的上下文长度远超人脑工作记忆，能够关联你遗忘的久远事项

## 使用步骤

### 前置准备

| 准备项 | 说明 | 建议位置 |
|--------|------|----------|
| 个人画像文件 | 描述你的背景、目标、兴趣领域 | `~/Documents/persona.md` |
| Obsidian 知识库 | 你的笔记、想法、待办事项 | `~/Obsidian/` |
| 任务清单 | 想做未做的事情列表 | 可放在 Obsidian 中 |

### 执行流程

1. **睡前启动 Claude Code**
   ```bash
   claude
   ```

2. **输入夜间探索 Prompt**
   - 使用版本一（通用探索）或版本二（系统扫描）
   - 可根据当日剩余 Token 量选择任务复杂度

3. **设置安全边界**
   - 明确禁止危险操作（删库、系统修改等）
   - 建议先在隔离环境测试

4. **次日查看报告**
   - Claude Code 会在对话历史中保留完整记录
   - 使用 `/history` 查看，或通过 `~/.claude/history.json` 找回

## 安全注意事项

⚠️ **必须设置的安全边界**：

```
- 不要执行 rm -rf /
- 不要删除系统文件
- 不要修改关键配置
- 不要执行未经确认的网络操作
- 保持在工作目录范围内
```

💡 **建议实践**：
- 首次使用先在 Docker 隔离环境测试
- 设置 Claude Code 的权限范围
- 重要数据先备份

## 进阶玩法

### 1. 自动化唤醒报告
结合 cron 或 launchd，设置早晨自动推送 Claude Code 生成的报告到 Telegram/邮件

### 2. 任务分级调度
```
高 Token 余额 → 深度研究/代码生成
中 Token 余额 → 文档整理/数据分析
低 Token 余额 → 快速总结/待办归类
```

### 3. 多 Agent 协作
- 一个 Agent 负责扫描和画像更新
- 一个 Agent 负责研究和探索
- 一个 Agent 负责报告生成和整理
