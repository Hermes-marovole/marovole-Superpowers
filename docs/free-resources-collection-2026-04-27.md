## 一、电子书资源（5个）

### 1. Z-Library ⭐ 推荐
- **网址**: https://zh.z-library.sk
- **特点**: 提供大量电子书，包含经典文学、经管书籍、学术资料等多种类型
- **格式**: EPUB、PDF、MOBI 等
- **语言**: 支持中文界面

### 2. WeLib
- **网址**: https://zh.welib.org
- **特点**: 提供图书、教材和学术资料，分类清晰，下载操作较为方便
- **适用**: 学术文献、教材资料

### 3. Anna's Archive
- **网址**: https://annas-archive.gl
- **特点**: 收录大量图书与论文，支持搜索和多格式下载
- **优势**: 资源全面，更新频繁

### 4. 苦瓜书盘
- **网址**: https://kgbook.com
- **特点**: 提供 PDF 和 MOBI 格式电子书，适合电纸书阅读，分类比较清晰
- **适用**: Kindle 等电纸书用户

### 5. GitHub 电子书宝库
- **网址**: https://github.com/jbiaojerry/ebook
- **特点**: 收集经典文学、经管励志、职场和技术类电子书，很多常见读书 App 的书都能找到
- **格式**: 多为 PDF/EPUB
- **更新**: GitHub 仓库形式，持续更新

## 使用建议

### 电子书
- **学术需求**: 优先使用 Z-Library、Anna's Archive
- **电纸书用户**: 苦瓜书盘的 MOBI 格式适合 Kindle
- **技术书籍**: GitHub 电子书宝库有较多技术类资源

### 影视观看
- **追美剧**: 在线之家更新快
- **国产剧/综艺**: 泥视频资源较全
- **简洁体验**: 发现 TV 广告少，体验好

### 音乐下载
- **无损音质**: FLAC Downloader

- **日常听歌**: 泡椒音乐、GD 音乐台操作简单
