## 项目简介

GitHub 上有个叫 **worldwonderer** 的作者，失业一周后推了一个网文写作 skill 包，8 天斩获 573+ 星。他在 README 末尾写了一句：「这套 skill 现在能让我度过找工作的过渡期 :joy:」—— 一句话证明三件事：作者自己在用、有真实付费意愿、工具被生活压力打磨过。

整套工具叫 **oh-story-claudecode**，覆盖：
- **扫榜**：跑遍起点/番茄/晋江实时榜单，看哪些题材在涨
- **拆文**：拿一本对标书拆解黄金三章、爽点设计、节奏曲线
- **写作**：按拆出来的结构搭大纲、写人物、出正文
- **去 AI 味**：预防 + 三遍去 AI 法 + 改写范例库 + 禁用词表
- **封面图**：书名题材分析 + GPT-Image-2 出图

## 最值得抄的 3 个设计

### 1. 文件系统管理长内容结构

一部长篇动辄几十万字、几百章——设定冲突、伏笔断线、时间线对不上，写到最后全靠记忆硬撑迟早翻车。

oh-story-claudecode 用文件系统把设定、大纲、正文、追踪拆开，每个维度独立维护：

```
{书名}/
├── 设定/
│   ├── 世界观/          # 背景、力量体系等，按主题拆文件
│   ├── 角色/            # 每个人物一个文件（沈栀.md、陆衍止.md）
│   ├── 势力/            # 每个势力/组织一个文件（天机阁.md）
│   ├── 关系.md          # 角色关系映射
│   └── 题材定位.md      # 题材核心梗+对标分析
├── 大纲/
│   ├── 大纲.md          # 全书卷级结构
│   ├── 卷纲_第一卷.md   # 每卷一个：爽点节奏+情绪弧线+人物弧线+伏笔+反转
│   ├── 细纲_第001章.md  # 每章一个：事件+钩子+爽点+悬念
│   └── ...
├── 正文/
│   ├── 第001章_章名.md
│   └── ...
├── 对标/
│   └── {对标书名}/
│       ├── 原文/            # 对标书原文章节
│       └── 拆文报告.md      # analyze skill 输出的拆文报告
├── 追踪/                # 连续性管理
│   ├── 伏笔.md          # 伏笔埋设/回收状态表
│   └── 时间线.md        # 故事内时间线
└── 笔记.md
```

**适用场景**：任何写书、写连载、写课程、写剧本的人，都能直接抄这套「设定/大纲/正文」三段式——比 Notion 数据库更轻、比 Markdown 单文件更结构化。

### 2. browser-cdp 复用浏览器登录态

复用真实浏览器的登录态抓数据，绕过 robots 和反爬虫，不用维护 cookie。任何需要从特定平台拉数据的场景都适用，不限网文。

### 3. references/ 按需加载知识库

整个 skill 包的核心壁垒在那 **16 个主题的知识库**，但做成了「调用 skill 时才加载」，不占用户上下文：

| 主题 | 核心内容 |
|------|----------|
| 大纲排布 | 五步大纲法、八节点结构、节点设计法、升级感设计 |
| 开头设计 | 开篇模式、前 500 字设计、黄金三章开头策略 |
| 人物设计 | 角色设定、人物提取、关系映射、动机链、群像 |
| 钩子技法 | 章尾 13 式、章首 7 式、段落级钩子、悬念编排 |
| 情绪设计 | 6 种弧形模板、期待感管理、题材赛道策略 |
| 题材框架 | 长篇八节点、短篇压缩三幕、8 大题材开头模板 |
| 对话技法 | 节奏、潜台词、信息控制、对话模式数据库 |
| 反转工具箱 | 类型、时机、误导底层路径 |
| 风格模块 | 对话、打斗、智斗、镜头式写作、装逼打脸、白描 |
| 高级技法 | 小纲四步法、高潮逆推、双线结构、AB 交织法 |
| 去 AI 味 | 预防、三遍去 AI 法、改写范例库、禁用词表 |
| 质量检查 | 通用、长篇专项、短篇专项、毒点排查 |
| 写作公式 | 21 大题材写作公式、三翻四震、感情线四阶段 |
| 女频写作 | 女读者偏好、情感描写、感情线模式、对标拆书 |
| 拆文方法 | 黄金三章、情绪曲线、结构拆解、知乎风格分析 |

## 快速上手

### 安装

**方式一**：直接告诉 Claude Code / OpenClaw：
```
安装这个 skill https://github.com/worldwonderer/oh-story-claudecode
```

**方式二**：命令行：
```bash
npx skills add worldwonderer/oh-story-claudecode -y
```

更新时重新执行同一条命令即可。

### 第一次使用建议

1. **已有 AI 写的稿子**：先跑 `/story-deslop` 丢给它，看看能改出什么样——输出最直观，快速判断这套工具是否适合你
2. **想扫榜看趋势**：直接 `/story-long-scan` 开始扫起点/番茄/晋江的实时榜单
3. **已有明确方向**：`/story-long-write` 跳到写作环节，工具会问你书名、题材、平台，然后自己搭大纲框架

## 成功背后的 3 个原因

1. **解决真问题**：中文网文作者用 AI 写作的痛点早就存在——模型对「爽点」「毒点」「卷标」这些黑话理解很弱，prompt engineering 又门槛高。把这些内功打包成 skill，门槛骤降。

2. **定位极准**：没去做「通用写作」那种大而泛的方向，直接卡死「中文网文」这个细分。Top 1% 的 Skill 几乎都是这种打法——挑一个被忽略的垂直场景做深。

3. **真实使用场景打磨**：README 那句「让我度过找工作的过渡期」——来自真实使用场景的工具，质量天然比「为开源而开源」的项目高一个数量级。
