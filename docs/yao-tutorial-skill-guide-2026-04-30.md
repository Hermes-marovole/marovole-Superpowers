## 简介

**Yao Tutorial Skill** 是一个面向教程成品生产的开源 AI Skill，由姚金刚开发并开源。它能够将任意主题或一组参考资料（网址、论文、GitHub 仓库、草稿）自动整理成一套完整的、带来源标注、带大纲结构、带章节配图、支持多格式导出的专业教程。

该工具特别适合制作"从入门到精通"类教程、系统化学习文档、产品或技术教材、方法论手册，以及需要正式交付的长篇教学内容。

## 详细内容

### 一、项目概述与核心功能

**核心定位**：输入一个主题或参考资料，输出一套完整的专业教程成品。

**主要功能模块**：

| 功能 | 说明 |
|------|------|
| **资料归一化** | 将输入主题、参考资料归一化为 `brief.json`，明确受众、目标、材料、格式和限制 |
| **智能研究补充** | 优先吸收用户资料；不足时自动补充官方文档、论文、GitHub、实践案例 |
| **来源登记与证据映射** | 生成来源登记和证据映射，避免教程变成无依据的泛泛写作 |
| **课程化大纲设计** | 用课程设计方法重构标题和大纲，章节既有专业体系，又能说人话 |
| **正文生成** | 默认中文约 5000-10000 字，以正式对外成品口吻呈现 |
| **自动配图生成** | 为每个编号章节生成 HTML 可视化配图，再截图嵌入正文 |
| **多格式导出** | 支持 Markdown、Word、PDF、HTML 四种格式输出 |
| **质量验证** | 运行验证脚本，检查章节、配图、引用、导出文件等完整性 |

### 二、工作流程详解

Yao Tutorial Skill 遵循 **8 步标准化工作流程**：

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 输入归一化                                          │
│  → 生成 brief.json，明确主题、受众、目标、材料、格式、限制    │
├─────────────────────────────────────────────────────────────┤
│  Step 2: 资料优先级处理                                      │
│  → 用户资料充足时以之为主，不足时补充外部研究                 │
├─────────────────────────────────────────────────────────────┤
│  Step 3: 来源登记                                            │
│  → 创建 source-register.md、evidence-map.md，记录所有信源    │
├─────────────────────────────────────────────────────────────┤
│  Step 4: 大纲设计                                            │
│  → 结合 tutorial-outline-and-writing.md 和                   │
│     course-design-principles.md 重构专业且易懂的章节结构      │
├─────────────────────────────────────────────────────────────┤
│  Step 5: 正文撰写                                            │
│  → 使用"第1章"、"1.1"格式，撰写 5000-10000 字完整教程        │
├─────────────────────────────────────────────────────────────┤
│  Step 6: 视觉配图生成                                        │
│  → 创建 visual-spec.json，运行 build_visual_pack.py          │
│  → 生成 HTML 配图画板，截图嵌入章节                           │
├─────────────────────────────────────────────────────────────┤
│  Step 7: 多格式导出                                          │
│  → 运行 export_tutorial.py，生成 HTML、DOCX、PDF             │
├─────────────────────────────────────────────────────────────┤
│  Step 8: 质量验证                                            │
│  → 运行 validate_package.py，检查完整性并报告                 │
└─────────────────────────────────────────────────────────────┘
```

**关键约束与质量门**：

- ✅ 用户资料足够时，不机械扩大搜索范围
- ✅ 外部来源优先级：官方/一手来源 > 论文 > GitHub > 权威实践分享
- ✅ 内部研究文件保留来源 ID；公开导出不显示 `[U1]`、`[X1]` 等角标
- ✅ 教程正文必须像正式出版物，不写"基于用户资料"等内部话术
- ✅ 每个编号章节都必须有对应视觉规格和嵌入配图
- ✅ HTML 报告使用居中内容容器、粘性目录、日期和章节跳转
- ✅ Word/PDF 默认不保留页眉页脚，避免路径、页码影响阅读

### 三、输出结构说明

完整的教程输出包结构如下：

```
output/
├── brief.json                    # 归一化后的任务简报
├── outline.md                    # 教程大纲
├── tutorial.md                   # 完整教程正文（Markdown）
├── research/
│   ├── source-register.md        # 来源登记
│   └── evidence-map.md           # 证据映射
├── visuals/
│   ├── visual-spec.json          # 视觉规格
│   └── index.html                # 配图画板
├── assets/
│   └── screenshots/              # 章节配图截图
└── exports/
    ├── tutorial.html             # HTML 版本
    ├── tutorial.docx             # Word 版本
    └── tutorial.pdf              # PDF 版本
```

### 四、技术架构与设计原则

**核心设计理念**：

1. **资料驱动的内容生成**
   - 以用户提供的资料为核心，AI 仅补充必要内容
   - 融入**低质量信源过滤机制**，确保内容可靠性

2. **课程营销学的应用**
   - 融入了作者三年前经营 MCN 时写的《课程营销学》底层逻辑
   - 标题和大纲面向用户利益、痛点和学习路径设计
   - 避免只堆砌专业术语，确保"说人话"

3. **视觉设计借鉴**
   - 排版与 UI 参考了 [@HiTw93](https://x.com/HiTw93) 的 kami 设计
   - 实现有质感的排版规范

4. **多格式适配**
   - 输出 PDF、Word 及 HTML 三种格式，方便不同场景使用
   - HTML 版本支持响应式布局和目录导航

## 快速参考

### 基本使用逻辑

```markdown
1. 输入任意主题及参考资料
2. AI 优先以参考资料为核心，按需补充高质量素材
3. 融入低质量信源过滤机制
4. 结合教程特点与用户偏好，生成定制深度教程
5. 输出 PDF、Word、HTML 三种格式
6. 按章节逻辑系统性输出，自动画图并插入
```

### 质量检查清单

- [ ] 资料归一化为 brief.json
- [ ] 来源登记完整（source-register.md）
- [ ] 证据映射清晰（evidence-map.md）
- [ ] 大纲结构合理（outline.md）
- [ ] 每个编号章节都有配图
- [ ] 导出 HTML/DOCX/PDF 完整
- [ ] 通过 validate_package.py 验证
