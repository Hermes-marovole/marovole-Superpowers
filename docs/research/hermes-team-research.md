## 二、核心能力

### 2.1 记忆系统（最大亮点）

Hermes Agent 的记忆系统是当前开源 Agent 中最完善的之一：

| 组件 | 功能 | 存储内容 |
|---|---|---|
| **MEMORY.md** | 环境信息和经验总结 | 项目脉络、解决方案、环境设定 |
| **USER.md** | 用户偏好 | 沟通风格、习惯、偏好 |
| **SQLite 全文搜索** | 历史对话检索 | 数周前的对话内容 |

**工作原理**：每次会话开始时，MEMORY.md 和 USER.md 自动注入系统提示，相当于 Agent 的「长期工作记忆」。

### 2.2 Skills 系统

- **自动生成**：Agent 在解决问题后自动总结经验，生成可复用的 Skill
- **程序性记忆**：将解决方案固化为步骤化指令
- **持续叠加**：运行越久，Skills 越丰富，Agent 能力越强

### 2.3 自我进化机制

**Self-Evolution** 技术：
- 使用 **DSPy + GEPA**（Gradient-based Evolution of Prompt Architectures）
- 自动优化 skills、prompts 和代码
- 形成学习闭环：执行 → 反思 → 优化 → 再执行

### 2.4 多平台消息

支持的消息平台：
- Telegram、Discord、Slack、WhatsApp
- Signal、Email、CLI
- 支持语音模式（包括 Discord 语音频道）

### 2.5 工具与集成

| 类别 | 具体能力 |
|---|---|
| 内置工具 | 47 个内置工具 |
| 浏览器自动化 | 网页抓取、自动化操作 |
| 视觉 | 图像理解、OCR |
| 图像生成 | AI 绘图 |
| 文本转语音 | TTS |
| MCP 集成 | 连接任意 MCP 服务器 |
| 搜索 | 网络搜索 |

### 2.6 部署灵活性

支持 5 种运行后端：
1. **Local**：本地直接运行
2. **Docker**：容器化部署
3. **SSH**：远程服务器
4. **Singularity**：HPC 环境
5. **Modal**：无服务器云

特点：容器硬化、命名空间隔离、安全模式

### 2.7 子 Agent 系统

- **隔离上下文**：每个子 Agent 有独立的对话、终端和 Python RPC 脚本
- **零上下文成本**：通过 RPC 管道传递任务，避免主上下文被撕裂
- **并行执行**：多个子 Agent 可同时工作

## 四、多 Agent 军团案例（苍何实践）

### 4.1 架构概览

苍何用 Hermes Agent 搭建的多 Agent 协同系统：

```
用户（飞书）
  ↓
总管 Agent（任务分发、进度跟踪）
  ↓
├── 市场总监 Agent（调研）
├── 产品总监 Agent（PRD）
├── 架构总监 Agent（架构设计）
├── 开发总监 Agent（代码开发，自主调用 Claude Code）
└── 测试总监 Agent（测试验收）
```

### 4.2 工作流程

1. **用户下达需求**：在飞书给总管发布任务
2. **市场调研**：市场总监完成调研报告，发给总管和用户
3. **产品设计**：基于调研结果输出 PRD
4. **架构审查**：架构总监审查 PRD 可实现性，可打回
5. **开发实现**：开发总监自主调用本地 Claude Code 进行开发
6. **测试验收**：测试总监全面测试，问题打回修复
7. **交付**：总管确认无误后告知用户“已就绪”

### 4.3 关键配置

- **模型**：推荐 Kimi K2.6（代码能力、长上下文、多轮任务稳定性）
- **消息平台**：飞书 Bot 接口
- **触发器**：定时任务（定时采集、预警）
- **工具**：文件操作、搜索、终端命令、浏览器自动化

## 六、风险与注意事项

1. **模型成本**：长上下文任务会消耗大量 token，需要控制费用
2. **安全审批**：Agent 有终端执行权限，建议开启命令审批模式
3. **学习曲线**：多 Agent 协同有一定的配置复杂度
4. **竞品更新**：OpenClaw 也在快速迭代，需要持续关注
5. **定时任务管理**：定时任务多了之后需要好的管理界面

## 七、结论

Hermes Agent 是当前开源 Agent 领域最具竞争力的框架之一，其核心优势在于：

1. **持久记忆 + 自动生成 Skills**：解决了传统 Agent “每次重头开始”的痛点
2. **自我进化**：DSPy + GEPA 让 Agent 能够越用越聪明
3. **极致的部署灵活性**：从本地到云端、从容器到 HPC 均可部署
4. **完善的消息平台支持**：覆盖所有主流消息平台

对于团队而言，Hermes Agent 最值得关注的是其多 Agent 协同能力——可以将市场调研、产品设计、开发实现、测试验收等环节自动化，构建一个 7x24 小时运行的 AI 研发军团。
