## 简介

GPT-Image 2 全量发布后，AI 画图从"能不能出图"变成了"能不能稳定、可控、可复用地出图"。苍何逆向整理了 **329 条** GPT-Image 2 提示词模板，全部开源到 GitHub。这个项目做的不是单纯收集提示词，而是把零散案例逆向整理成一套更适合 Agent 和自动化工作流调用的 **Prompt-as-Code** 资产。

核心目标只有一个：**把"散文式提示词"压缩成"结构化协议"**。当你需要批量出图、做模板系统、接进生产流程时，这种整理方式比单纯堆案例更有价值。

## 核心特点

### 🧱 原子化 Schema 注入

别再写小作文了。把所有视觉要素（主体、光影、材质、排版）全部降维成了 **JSON/YAML 结构化组件**。你的 Agent 闭着眼都能稳定解析，零幻觉。

### ⚙️ 零配置工作流

抹平使用门槛，随时无缝接入你的大模型数据管线。讲真的，看它们自己协调干活出图的时候，真有一种当甲方的快感。

### 🧬 多维决策矩阵

针对 GPT-Image 2 强大的文本排版能力，引入了精确的空间坐标系约束。彻底干掉传统 NLP 控制不了画面排版的技术盲区。

## 精选案例与提示词模板

### 1、直播画面

这种图，逼真到离谱。

**提示词模板：**
```
生成一张直播间的图片，直播间氛围是月下美女跳舞的画面，直播间有很多人评论
```

**变体 - 汉服小哥哥：**
```
生成一张直播间的图片，直播间氛围是帅哥讲解汉服的画面，直播间有很多人评论
```

---

### 2、手绘风格城市地图

GPT-Image 2 在中文乱码这块比之前的模型好太多了。

**提示词模板：**
```
生成一张手绘水彩风格的「这里输入城市名」城市地图，包含的当地特色美食、地标建筑及城市特色
```

**示例城市：** 西安、新疆

---

### 3、海报设计

随手拍产品照片，一句话生成宣传海报。

**提示词：**
```
帮这个产品生成宣传图
```

就这么一句话，GPT-Image 2 自己脑补了所有设计细节。

---

### 4、拆解图（爆炸视图）

**提示词模板：**
```
生成一张AI眼镜的爆炸视图，包含每个组件的名称以及这款产品的几大核心卖点。
```

**通用模板：**
```
生成一张【产品名】的爆炸视图，包含每个组件的名称以及这款产品的几大核心卖点。
```

---

### 5、技术详解图

**提示词模板：**
```
帮我生成一张【这里填入你要详解的名词】技术的详细讲解图
```

**示例：** RAG 技术详解图、任意技术概念可视化

---

### 6、朋友圈截图生成

它能生成非常逼真的朋友圈截图。强烈建议把这篇转给父母看看，现在照骗的成本真的太低了。

> ⚠️ 提示词就不放了，说真的，这玩意儿细想挺恐怖的

---

### 7、个人网页设计

一句话生成完整的个人主页设计，效果相当可以。

---

### 8、诗词意境图

**提示词模板：**
```
帮我生成一张《短歌行》的意境图，带整篇《短歌行》文字
```

---

### 9、长卷图

GPT-Image 2 支持非常多尺寸直出，长卷图这种尺寸也完全没问题。而且文字几乎零乱码。

**提示词模板：**
```
帮我生成一张《赤壁怀古》的长卷图，带整篇《赤壁赋》文字
```

---

### 10、个人主页/网页设计

让它设计个人主页，效果相当可以。

## 使用方法

### 三步走策略

1. **确定输出类型** → 先在精选案例里确定你要模仿的输出类型
2. **找相近案例** → 去完整画廊里找相近案例，抄结构，不要只抄风格词
3. **填入模板** → 回到模板页，把你的业务变量填进通用模板或 JSON 模板

### 给 Agent 使用

> 推荐直接给 Claude Code 或 Codex 这样的 Agent 调用。

以前还得配合什么 skill 来搞，现在通通不需要了。Codex 直接调用 GPT-Image 2 来生图，生成一张封面图一分钟都不到。

**作者目前的创作流程：**
- 文章在 Obsidian 里写完
- Codex 直接调 GPT-Image 2 生成封面图
- 自动填充进文章字段
