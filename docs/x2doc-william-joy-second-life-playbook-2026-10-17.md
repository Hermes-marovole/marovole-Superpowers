## TL;DR

- 演讲是讲者去年"第二人生"演讲的续篇，分四章：2024–2026 全品类投资复盘 → 建立自己的 Trading Lifestyle → 有身体的时间才是资产 → 多做好事（运气与社会责任）。
- 投资部分的核心不是标的，而是"先认清自己是哪类交易者，再让 AI 替你执行纪律"。讲者认为 AI 用于执行交易纪律的价值，比投研类用途被低估得多。
- 健康部分是一份"普通人、几乎不花钱"的抗衰清单（日晒、睡眠环境、肌酸、Omega-3+D+运动、表观遗传年龄检测等），讲者自称 33 岁、检测身体年龄 18 岁。
- 结尾转向价值观：推翻自己去年的"99% 汗水 + 1% 天赋"，改为"成功 99% 来自运气"，由此推出交税、利他、"多做好事"。
- 推荐帖作者强调"不要看 AI 总结，值得看原片"——本文是索引与要点，不替代原片。

## 原帖核心内容（按演讲章节）

### 2. 建立自己的 Trading Lifestyle（TL）

三步法：

1. **Establish awareness（建立觉知）**：回答几个问题——你平时用哪些策略？踏空和亏损哪个更难受？自己盯盘做高收益组合 vs 交给专业的人换回自己的时间？集中押注核心资产 vs 充分分散（引用 1981 年诺奖得主托宾的分散化思想）？
2. **Invest and live with your TL，建立耐受**：
   - 讲者自己"踏空难受、亏损无感"——普通人大多持有现金，本就处于踏空状态；专业投资人最不能接受的是一轮 AI 浪潮里没拿核心资产。
   - 左侧（A 类，Peter Lynch / Buffett 式）vs 右侧（B 类，趋势交易者）：同样买在 100 后下跌，A 类越跌越加，B 类跌 10% 就该斩仓。决策完全相反，没有对错，只看你是谁。
   - "所有核心资产长期看都会涨"：理由是美元、人民币长期持续扩表（讲者引用《货币金字塔》类书籍的数据，转写里的具体增速数字明显有误，此处不引用），四大央行因债务不可能停止印钞。所以对"BTC 回 10 万 / 黄金回前高 / 海力士回前高"答"长期都是 yes"，但"能告诉你明天涨不涨的人一定是骗子"。建议自己用 AI 建模跟踪 M2、美联储资产负债表、央行广义货币等指标。
3. **用 AI agent 去 comply with 你的 TL**：现有 AI+投资应用约 95% 是投研类（讲者团队自建 17 个工具也多属此类），被忽视的是"让 AI 执行你的纪律"。例：某存储股在市场情绪最差时按计划买入，四天后到预设价位卖出一半，约 40% 收益——人在亢奋时往往不卖，AI 不会。

实物资产的定价逻辑：
- 99% 实物买到手即贬值，剩下 1% 会涨。宝可梦是全球 IP 收入第一（讲者称已连续多年第一）。
- 判断维度：**稀缺、无用性、易存储、流通性**。转述王宁在湖畔的话："物品越有用，价值存储越低"——科技产品必贬值，画作可升值。
- 易存储：威士忌比红酒好存，卡牌最好存、又小，适合全球变现；但红酒、雪茄是消耗型奢侈品，消耗快反而推高稀缺。
- **实物资产不可能三角**：资产适配性 / 资产安全 / 人身安全，任何实物资产都无法三角全占（例：核心城市顶级房产 vs 名表的人身安全差异）。要根据自己的 TL 接受缺的那一角。

人生层面：
- **真我价值三角**（讲者称学自邵逸波的企业家灵修营）：你最欣赏的人的单一品质 / 陪你度过黑暗期的单一品质 / 你天性里的单一品质。讲者自称花了很长时间才找到第一版，之后又迭代多次。
- 人生意义在"传承"与"体验/快乐"两端之间，讲者从传承端往体验端移动了不少。
- "拾起与放下"是自然循环：热爱一个策略或爱好一段时间后放下，过段时间可能又拾起。

### 3. Bodily Time：有身体的时间才是资产

讲者自称 33 岁，赛后检测身体年龄 18 岁，没用换血等激进方法。以下为讲者个人清单，未经本文核实：

| 类别 | 做法 |
|---|---|
| 光照 | 每天晒太阳 10 分钟 |
| 监测 | Oura 戒指（多数情况够用）+ Polar 心率带；戴 3–6 个月后对身体理解上一个台阶 |
| 睡眠硬件 | Eight Sleep 温控床套，自述深睡时长明显增加 |
| 冷水 | 面部 T 区多碰冷水 / 敷面膜，利用潜水反射，讲者称可提高 HRV、降低皮质醇 |
| 入睡 | 睡前用筋膜枪轻敲枕下 3 分钟缩短入睡潜伏期；睡前站立走动 5 分钟，上床即睡 |
| 卧室 | 全遮光；室温全年 21–24°C（引自《睡眠革命》）；四季同一条被子；床只用来睡觉，不在床上工作刷手机 |
| 补剂 | 肌酸每天 3–5 克（女 3、男 5，中老年和非运动员同样适用）；Omega-3 + 维生素 D + 运动 |
| 检测 | 定期测表观遗传时钟：表型年龄、预测寿命、衰老速度（DunedinPACE，>1 表示加速衰老） |
| 其他 | 做点家务、"学会浪费时间"；定期高压氧舱（舱内不能带电子设备）；游戏利弊并存，讲者自己未想清楚 |

讲者还提到个人健康 AI 看板（转写为 "William Joy.pro"，含 Evidence Hub 补剂证据中心），网址拼写未核实。

两个预测：
- 未来十年更多人成为"投资人 + 运动员"组合：优质资产因马太效应更集中，很多人持有核心资产 + 高质量单身 + 保持好身体状态。
- 男性审美与"美商"会大幅提升。
- 未来普通人只剩两类有价值资源：**个人数据与 identity**（把账号身份挂到平台上供需求方使用）、**自己的身体**。

### 4. 多做好事：运气与社会责任

- 推翻去年"成功 = 99% 汗水 + 1% 天赋"，引用 2022 年搞笑诺贝尔经济学奖课题（"运气比天赋更重要"）、纽约时报专栏作家 Nicholas Kristof、Robert Frank《成功与运气》、Elizabeth Warren"没有人是靠自己发财的"、Milanovic"全球收入差异约一半可由居住国与该国分配解释"。
- 讲者自述 99% 成功来自运气：哈佛临时多出的插班名额、2015 年创业潮、湖畔、中国体育发展红利。
- 观念转变：早年想方设法合理避税，现在认为交税非常重要。两个论据：
  - 案例一（美国调研）：多数人宁可在好路上开保时捷，也不愿在坑洼路上开法拉利——公共品决定体验上限。
  - 案例二（讲者自己的思考）：在国内生活成本约为纽约的三分之一，却持有全球核心资产，本质是"占了大量廉价劳动力的便宜"。
- 精英的轨迹模型：早期强个人能动性、反集体主义（讲者提到与孙宇晨聊过）；成功后应转向社会融合与利他。"创业本身是往卡好的齿轮里硬塞一个齿轮，带有原罪。"
- 提升运气：扩大暴露面、做能复利叠加的事、保持身心平衡，最重要的是**多做好事**——讲者 25 年来的 QQ 网名就是"多做好事"；"论迹不论心"，功利地做了好事也有价值。
- 以一首陈奕迅歌曲收尾。

## 我的吸收判断

- **可复用能力**：
  - "Trading Lifestyle → 让 AI 执行纪律"可以直接迁移成一个 agent 场景：把个人的买卖规则、仓位上限、止盈止损写成规则文件，由 agent 盯价提醒或执行——这比再做一个投研 bot 更有差异化。
  - "实物资产不可能三角"和"无用性 / 易存储 / 流通性"四维，是一个简洁的收藏品类评估框架。
- **值得沉淀到 skill / workflow 吗**：暂不新建 skill。健康清单可以作为补剂选型与内容选题的输入，对照已有 supplement-selection 流程做证据核查后再用。
- **对 AI × Product × Biohacking / Super Individual 的价值**：讲者本人就是"投资 + 运动员 + 健康数据驱动"的超级个体样本；"有身体的时间才是资产"适合作为个人号健康/财富交叉选题（大流量讲法）。灵知AI 侧可参考"肌酸 / Omega-3 + 维 D + 运动"这类大众可执行组合，但必须先做证据分级。
- **风险或待验证点**：
  - 所有业绩、纪录、"身体年龄 18 岁"均为讲者自述。
  - 健康部分有几条讲者称"顶刊已证实"（高压氧舱保养、冷水敷 T 区降皮质醇等），证据强度参差，未核实前不能直接对外传播。
  - 投资部分是个人主观判断与特定时点操作，不构成投资建议；"核心资产长期必涨"有幸存者偏差。
