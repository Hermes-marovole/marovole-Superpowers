# 阶段 10：review 审稿与修改

目标：用独立的审稿视角找出 lint 查不出的问题，并修改到达标。

## 逐章审稿

每章派一个审稿子代理（不能是写这一章的那个），交接说明：

```
你是《<书名>》第 <NN> 章的审稿人，只审不写。
读：<项目目录>/07_drafts/ch<NN>.md、对应简报 briefs/ch<NN>.md、02_voice/voice_profile.md、
<SKILL_DIR>/references/compliance-cn.md、<SKILL_DIR>/templates/review.md；
证据核对：从正文里随机挑 3 个 [E编号]，到 06_evidence/evidence_bank.md 查对应条目，核对正文的数字、措辞强度和证据等级是否一致。
病例核对：每个 <!-- src: C编号 --> 都到 01_materials/material_bank.md 核对，正文不能添加素材里没有的关键事实。
按 templates/review.md 打分并给出修改清单，每条修改写"原文片段 → 改成"。
写到 <项目目录>/08_reviews/ch<NN>.md。回复：各维度分数和必须修改的条数。
```

## 评分维度（1–5 分，详见 `templates/review.md`）

钩子、论点单线、解释清晰、证据准确、可执行性、文风一致、合规、真实性。

**通过条件**：合规和真实性都是 5 分，其他各项 ≥ 4。

## 修改

1. 没通过的章，用 resume 交回原写作子代理，要求它按 `08_reviews/chNN.md` 逐条修改，改完重跑 lint。
2. 再派审稿子代理复审。最多 3 轮。3 轮后仍不通过，保留得分最高的版本，在 `notes` 和交付报告里写明剩余问题。

## 全书一致性审稿与医学科学性交叉审计（必须在进入封面/插图与排版阶段前完成！）

所有章节通过后，先运行 `python3 SKILL_DIR/scripts/book_check.py <项目目录>`（检查章数、三幕比例、单章占比、免责声明数量、概念复现、交叉引用），把输出交给全书审稿子代理。

### 第一步：全书结构与文风一致性审稿（写 `08_reviews/book.md`）
- 用 grep 检查每个命名概念在各章写法一致，出现章节与概念复现表相符
- 正文里的"第 X 章"交叉引用都指向正确章节
- 开场人物在结语回收；每章主病例在章尾回收
- 同一个比喻、同一个病例、同一个研究没有在多章重复展开
- 术语前后一致（同一事物不出现两个叫法）
- 相邻章节的衔接句连贯

### 第二步：全书医学科学性挑刺审查（必做！先读 `references/scientific-audit.md`）
**核心原则**：科学性审查必须在绘制章节信息图（阶段 12）与排版导出（阶段 13）**之前**完成（防止错误数字被画进图片返工）。推荐派发 2 个并行的高推理审稿子代理（如 `GPT-6 Astra` 或独立审稿子代理），对照 `06_evidence/evidence_bank.md`、`01_materials/material_bank.md` 及 PubMed/指南原文，逐字挑刺全书章节（并延伸覆盖阶段 11 的前言、结语与附录），重点清查 `references/scientific-audit.md` 所列的六大高危区：
1. **作者本人论文、地方标准与门诊个案**：严禁把细胞因子芯片写成非靶向代谢组学、严禁把基因多态性阴性结果写反、严禁把国家指南的具体数字塞进作者牵头但只写原则条款的地方标准里、核对个案胰岛素单位（`pmol/L ÷ 6.0 = μIU/mL`）与体成分算术逻辑；
2. **临床公式、单位换算与自测防呆**：HOMA-IR 等公式必须注明胰岛素单位为 `μIU/mL`（警示 `pmol/L` 须先除以 `6.0`）、测试餐生熟重碳水克数换算（`50g 总碳水 ≈ 65g 生米 ≈ 170–200g 熟饭`）、跨章人物复测数值与诊断切点自洽；
3. **国内外指南切点**：核对不等号、标准化实验室 HbA1c 诊断地位、减重目标（`7%` vs `5%`）、分龄与分仪器切点（如 AWGS 2025 五次起坐 50–64 岁 `≥10.0s` vs ≥65 岁 `≥12.0s`、DXA vs BIA 切点）；
4. **临床试验统计学严谨性**：严禁混拼不同随访报告的分子分母（如大庆 2024 事后分析 vs 2014 年 23 年随访）、区分“中位随访时长”与“平均发病推迟年数”、尊重 `p` 值与 `95%CI`（未达显著不得写“显著减少/极强相关”）、标明 RCT 受试者人群与时点边界；
5. **生理与病理机制**：区分骨骼肌 `GLUT4` 与肝细胞 `GLUT2`、肌肉收缩多通路（`AMPK/CaMKII/Rac1`）、静脉“第一时相”与口服“早相反应”、缺铁性贫血（使 HbA1c 假性偏高）与溶血（假性偏低）、OGTT 前限碳水（使结果假性偏高）；
6. **用药、慢病与监管边界**：区分保钾药/CKD（防高钾血症）与胰岛素/磺脲类（防断碳水低血糖）、阿卡波糖低血糖急救必须用葡萄糖（不可用蔗糖/方糖）、肝硬化蛋白需求（`1.2–1.5 g/kg/d` 防肌少，勿列为高蛋白禁忌）、保健食品原料（如刺五加）与普通药食同源目录区分、食物 IgG 检测共识边界。

将审查报告写入 `08_reviews/scientific_audit.md`（按 A 级硬伤、B 级边界瑕疵、C 级轻微问题分级列出）。
**闭环修复**：发现任何 A 级或 B 级问题，必须**先修正 `06_evidence/evidence_bank.md` 源头条目**，再派写作子代理用 `patch` 逐章修复正文（阶段 11 写完后同样用同一清单核查并修复 `09_backmatter/*.md`），改后重跑 `lint_chapter.py` 确保退出码为 0。
