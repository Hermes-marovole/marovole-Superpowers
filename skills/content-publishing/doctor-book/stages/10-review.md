# 阶段 10：review 审稿与修改

目标：用独立的审稿视角找出 lint 查不出的问题，并修改到达标。

## 逐章审稿

每章派一个审稿子代理（不能是写这一章的那个），交接说明：

```
你是《<书名>》第 <NN> 章的审稿人，只审不写。
读：<项目目录>/07_drafts/ch<NN>.md、对应简报 briefs/ch<NN>.md、02_voice/voice_profile.md、
<SKILL_DIR>/references/compliance-cn.md、<SKILL_DIR>/templates/review.md；
证据核对：从正文里随机挑 3 个 [E编号]，到 06_evidence/evidence_bank.md 查对应条目，核对正文的数字、措辞强度和证据等级是否一致。
病例核对：每个 <!-- src: C编号 --> 都到 01_materials/material_bank.md 核对，正文不能添加素材里没有的关键事实。
按 templates/review.md 打分并给出修改清单，每条修改写"原文片段 → 改成"。
写到 <项目目录>/08_reviews/ch<NN>.md。回复：各维度分数和必须修改的条数。
```

## 评分维度（1–5 分，详见 `templates/review.md`）

钩子、论点单线、解释清晰、证据准确、可执行性、文风一致、合规、真实性。

**通过条件**：合规和真实性都是 5 分，其他各项 ≥ 4。

## 修改

1. 没通过的章，用 resume 交回原写作子代理，要求它按 `08_reviews/chNN.md` 逐条修改，改完重跑 lint。
2. 再派审稿子代理复审。最多 3 轮。3 轮后仍不通过，保留得分最高的版本，在 `notes` 和交付报告里写明剩余问题。

## 全书一致性审稿

所有章节通过后，先运行 `python3 SKILL_DIR/scripts/book_check.py <项目目录>`（检查章数、三幕比例、单章占比、免责声明数量、概念复现、交叉引用），把输出交给全书审稿子代理。再派一个子代理做全书审稿，写 `08_reviews/book.md`：

- 用 grep 检查每个命名概念在各章写法一致，出现章节与概念复现表相符
- 正文里的"第 X 章"交叉引用都指向正确章节
- 开场人物在结语回收；每章主病例在章尾回收
- 同一个比喻、同一个病例、同一个研究没有在多章重复展开
- 术语前后一致（同一事物不出现两个叫法）
- 相邻章节的衔接句连贯

发现的问题交给对应章节的写作子代理修改，改后重跑 lint。

## 完成标准

每章审稿通过（或已记录例外），`08_reviews/book.md` 里的问题都已处理，所有章节 lint 退出码为 0，`book_check.py` 没有 FAIL（免责声明数量要等前言写完才能达标，此时可暂缓这一项），状态改为 `reviewed`。把 `stages.review` 改为 `done`。
