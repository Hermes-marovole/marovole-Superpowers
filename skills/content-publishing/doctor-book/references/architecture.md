# 结构与定位：读者、框架、人设、三幕、六种章型、排序与闭环

本文件服务两个阶段：`stages/04-positioning.md` 读"定位"一节；`stages/06-architecture.md` 读全文。写作子代理在执行 `stages/09-drafting.md` 时只需读 `references/chapter-template.md`，不必读本文件。

所有数字都是预算和门槛，不是文学评价。验收以 `scripts/lint_chapter.py`、`scripts/book_check.py` 的输出为准；本文件给的是"怎么写才能过"。

## 一、定位

### 1.1 读者画像怎么写

一份能用的读者画像必须能让门诊医生说出"这样的人我一周见五个"。写法固定为五句，缺一句就重写：

```
主读者：<年龄区间> <性别>，<城市层级> <职业或身份>，<一个具体的身体事件或体检数字>。
他已经试过：<1–3 件具体的事，含花了多少钱、坚持了多久>。
他最担心的不是"健康"，而是：<一件会发生在他身上的具体的事>。
他会在：<一个具体的阅读场景> 读到这本书。
他愿意付钱的理由：<一句话，说的是他省下的时间、钱或恐惧>。
```

正例（可直接改成你的主题）：

> 主读者：44 岁女性，二线城市，事业单位行政，去年体检空腹血糖 6.1 mmol/L、腰围 86 cm，报告上写着"建议内分泌科随诊"，她没去。
> 她已经试过：三个月不吃主食（瘦了 3 公斤，半年后回来了）、买过两箱代餐、跟着短视频做过每周三次 HIIT（膝盖疼了两周）。
> 她最担心的不是糖尿病，是"我妈 58 岁开始打胰岛素，我不想走同一条路"。
> 她会在晚上十点孩子睡后、在手机上读，一次读 15–20 分钟。
> 她愿意付钱的理由：她想在下次体检前知道自己该加查哪两项、该问医生哪三个问题。

反例（不可用）：

> "关注健康、追求品质生活的中青年人群。"——集合名词做主语，没有一个人，没有数字，没有场景。

六条硬规则：

1. 主语必须是一个人，不能是"人群""大众""都市白领"。
2. 至少一个数字：年龄、指标、年份、金额、时长，任选其二。
3. 至少一件"已经试过并失败"的事，写清花了多少钱或坚持了多久。
4. "最担心的"必须是一件会发生的事（失明、透析、截肢、被孩子送进养老院），不能是"亚健康""状态不好"。
5. 写出阅读场景：通勤、夜班后、陪床、体检报告出来那晚、复诊排队时。
6. 次要读者最多两类，只写"他和主读者的差别"，不重复画像。

三条检验：

- **门诊复述测试**：把画像念给一位同专科医生，他能否立刻说出一个真实病人的样子。
- **书脊测试**：这个人走过书店或刷到链接，能否在 3 秒内认出"这是写给我的"。
- **付费测试**：他会不会为它放弃一顿外卖的钱。答案含糊就说明读者还不够具体。

### 1.2 命题转向

全书的命题转向是四句话，写在 `03_positioning/positioning.md` 的"命题转向"一节：

```
1. 你以为的问题是：<患者原话式的 A>
2. 按 A 去做，代价是：<时间 / 钱 / 尊严 / 机会，写具体>
3. 真正的问题是：<C，一句话，含一个新名字>
4. 为什么现在才有人告诉你：<D，制度 / 时间尺度 / 分科 / 证据更新，不写阴谋>
```

三本样书的转向类型，各对应一种写法：

| 类型 | 样书 | 转向句的实质 | 适用主题 |
|---|---|---|---|
| 时间尺度转向 | Outlive 第 1 章 | 不是"怎么死"，是"死之前的十年怎么活"；旧医学只在急性期有效 | 慢病、衰老、体检、预防 |
| 归因转向 | 好能量 第 1–2 章 | 不是五个科的五种病，是同一个根因的五个出口 | 多症状共存、反复就诊、专科之间踢皮球 |
| 标准转向 | 营养圣经 第 1–2 章 | 不是"有没有病"，是"在不在最佳区间" | 营养、功能、亚健康、指标优化 |
| 决策转向 | 营养圣经 第 43–49 章 | 不是"该不该补"，是"凭什么这样定你的量" | 用药、补充剂、手术选择 |

四条检验：

1. **一句话说清**：不借助比喻也能讲完，讲不完说明 C 还没想清楚。
2. **旧解释值得尊敬**：能说出旧解释在什么情况下是对的、救过多少人。写不出它的成功史，读者会认为你在打倒稻草人。
3. **C 能落地**：C 必须对应至少一个可测指标或一个可执行动作，否则只是一个更漂亮的说法。
4. **D 不是阴谋**：写激励、时间、分科、样本量、指南更新速度。凡出现"他们不想让你知道"，删掉重写（见 `references/compliance-cn.md` 红线 3）。

### 1.3 核心框架：1 个总概念 + 3–5 个命名子概念

总概念是全书的名字，子概念是全书的骨架。写法与 `templates/positioning.md` 的"核心框架"表一一对应：总概念写在 `- 总概念：` 一行；每个子概念一行，四列（名称 / 一句话定义 / 对应章节 / 可测指标或可执行动作）。

**命名规则（8 条，逐条检验）**

1. **2–6 个汉字，上限 8 个**。超过 8 个字，读者记不住，也没法在章名和目录里复现。
2. **用常用字，不用生造词**。英文缩写只能做副标（"胰岛素抵抗（HOMA-IR）"），不能做概念名。
3. **名字里带动作或方向**：溢出、错配、透支、淤积、漏水、堵车、刹车、排队。带"系统""理念""体系"的名字一律重命名。
4. **每个子概念必须绑定一个指标或一个动作**。绑定不上的，是口号，不是概念。
5. **子概念之间要有关系**：层级（总—分）、先后（第一步—第二步）或并列杠杆（三个可以分别调的东西）。三个互不相干的词，读者记不住。
6. **门诊语言测试**：一个 50 岁患者能不能复述这个词，并且用对。不能，就换成他嘴里会说的词。
7. **搜索测试**：这个名字不能已经是别的畅销书、保健品或某个病的别名。撞车就换。
8. **全书只用一种写法**。好能量把"好能量"和"良好能量"混用了 148 次和 144 次，品牌力被自己稀释——这是反面教材。同义词替换是 AI 腔，不是文采。

**六种可用的命名取材领域**（示例仅示意，不得直接采用）

| 取材 | 命名感 | 示例 | 适合的解释 |
|---|---|---|---|
| 身体物件 | 具体、可画 | 胰岛素水位、血管路面、肌肉银行 | 代谢、心血管、衰老 |
| 账本/预算 | 有进有出、可算 | 代谢账本、睡眠负债、炎症利息 | 累积型问题、代偿 |
| 交通/道路 | 有瓶颈、有事故 | 十字路口、单行道、收费站 | 分诊、流程、就医路径 |
| 机器/工厂 | 有工序、有零件 | 总承包商、流水线、备用发电机 | 机制、器官功能 |
| 地图/坐标 | 有位置、有方向 | 三张地图、风险坐标、时间窗口 | 决策、分层 |
| 关系/契约 | 有双方、有违约 | 和身体的合同、和医生的分工 | 依从性、医患沟通 |
| 流域/上下游（本土慢病归因母本） | 治标与治本一目了然 | 上游（吃动睡生活方式）、中游（血压血糖血脂指标异常与药物控制）、下游（心脑肾靶器官并发症） | 慢病溯源、解释为什么光吃药不够 |
| 建材 vs 燃料（本土营养去向母本） | 打破“少油少肉就是健康”迷思 | 结构型建材（优质蛋白+磷脂/好脂肪，修补细胞膜与血管砖瓦） vs 能量型柴火（碳水供能） vs 调度员（维生素矿物质） | 营养失衡、隐性饥饿、肌少与代谢修复 |

**检验标准（5 条，全部通过才能进阶段 5）**

| 检验 | 通过的样子 | 不通过怎么办 |
|---|---|---|
| 一句话转述 | 陌生人听一遍，能用自己的话复述全书主张 | 子概念超过 5 个，或总概念太抽象 |
| 可测/可做 | 每个子概念都有 ≥1 个指标或动作，写在表里 | 删掉不能落地的子概念，不要凑数 |
| 可画 | 能用 1 张图（≤6 个方框）画完关系 | 关系没想清，先画图再命名 |
| 唯一 | 换一位同专科医生，写不出同样的框架 | 框架太通用，回素材库找 V、A 条目 |
| 复现 | 每个概念至少在 3 章出现（`scripts/book_check.py` 低于 3 章报 WARN） | 删掉只出现 1–2 次的概念，并入别的概念 |

配额：全书 1 个总概念、3–5 个子概念；每章新引入概念 ≤2 个；每章复现概念 ≥1 个。超过这个数，读者会把书当成术语表。

### 1.4 权威三角

三个阶段文件都要求写"权威三角"（`stages/04-positioning.md` 第 4 步、`templates/positioning.md` 的"作者人设"栏）。三个角缺一个，书的可信度就塌一角。

| 角 | 要写什么 | 素材来源 | C 级素材怎么办 | 失败写法 |
|---|---|---|---|---|
| 临床资历 | 从医年限、职称、年门诊量、管过什么病房、做过哪类手术 | B 条目 | 只写能核实的履历事实，不形容词 | 头衔堆叠、医院排名、"从医三十年"重复五次 |
| 个人经历 | 一次误判、一次失败、一次自己或家人的病 | S 条目 | 写"我见过的最常见的一幕"，明确不是亲历；缺就写 `【待核实】` | 编故事、把别人的病例写成自己的 |
| 独有方法 | 一套自己的判断顺序、清单、分诊规则 | V、A 条目 | 从专科临床逻辑提炼，标注"本书使用的顺序" | 卖课、卖方案、"我的疗法" |

三种失衡：

- **只有资历** → 像教科书。读者尊敬但不亲近，翻两章就放下。
- **只有经历** → 像自传。读者感动但不知道能做什么。
- **只有方法** → 像卖课。读者警惕，且合规风险最高。

不用的第四角：患者感谢信、媒体曝光、粉丝数、获奖。这些是营销素材，写进选题策划书（`stages/12-package.md`），不写进正文。

### 1.5 人设原型（5 个，选 1 个）

体制内医生可用的五种人设。选定后写入 `03_positioning/positioning.md` 的"人设原型"栏，全书语气按它执行，不混用。

#### 原型 A：临床一线的翻译者

- **适合**：三甲医院主治及以上，门诊量大，爱解释机制，能把研究翻译成决策。
- **开篇方式**：一个"说不通"的瞬间——检查都正常，人却在变坏；指南说观察，病人问观察什么。
- **语气**：耐心、有结构、愿意停下来定义词。常用"换句话说""你可以把它想成"。
- **优势**：最能承载机制章和证据章；读者信任度高。
- **风险**：容易写成教科书；容易有优越感（"很多医生不知道"）；机制段太长会压掉人。
- **约束**：每 1,000 字至少出现一次具体的人或具体动作；禁止"众所周知""临床上我们常常见到"。
- **样书参考**：Outlive 的第 2、7 章。

#### 原型 B：门诊里说不完的话

- **适合**：门诊时间被压缩（每半天 30–60 个号），反复被同一个问题问住，素材多是对话和原话。
- **开篇方式**：一句被打断的话，或患者走到门口又回头问的那一句。
- **语气**：短句、口语、承认时间不够。常用"这句话我那天没答完""后面还有 27 个号"。
- **优势**：最像真人；最能处理读者的羞耻和恐惧；最适合 C 级素材（不需要病例细节，只需要对话）。
- **风险**：容易变成吐槽体制（越线，见 `compliance-cn.md`）；容易只抱怨不给方法；"我"太密会显得自我沉溺。
- **约束**：抱怨只能出现在冷开场和案例回收，且每次不超过 120 字；机制段必须把"我"退到幕后。
- **样书参考**：好能量第 3 章（13 天决策现场）、第 7 章（手术室里的睡眠剥夺）。

#### 原型 C：病房里的记录者

- **适合**：住院部、ICU、肿瘤、外科、急诊，手上有完整病程和强场景。
- **开篇方式**：一个夜班、一台手术、一张片子、一次交接班。
- **语气**：克制、白描、少形容词。让细节说话，不解释情绪。
- **优势**：开场最有力量；疾病章的说服力最强。
- **风险**：把病人当素材；恐惧过载（`scripts/lint_config.json` 的 `fear_action_window` 会抓）；读者只记得惨，不记得方法。
- **约束**：每个可怕场景后 400 字内必须给动作或路径（lint 硬规则）；病例必须脱敏并标 `<!-- src: C## -->`。
- **样书参考**：Outlive 第 1 章（急诊室）、第 6 章（脂肪肝手术台）。

#### 原型 D：我也在名单上

- **适合**：自己有慢病、体检异常、家族史，或亲人生过这场病。
- **开篇方式**：自己的化验单、自己的体重、家里人的病历。
- **语气**：第一人称密集、自嘲、允许失败。常用"我也没做到""我现在还在改"。
- **优势**：共情最强；能把"你应该"变成"我们一起"；适合 essay 章和结语。
- **风险**：把个人经验当证据（lint 抓不到，审稿要抓）；暴露家人隐私；变成康复日记。
- **约束**：个人故事必须服务一个论点，讲完要接机制或证据；家人的部分必须取得同意或模糊化到不可识别。
- **样书参考**：好能量母亲线（引言、第 2、3、9 章）、Outlive 第 17 章。

#### 原型 E：带教查房的老师

- **适合**：主任医师、教授、科普账号有规模，习惯结构化输出。
- **开篇方式**：一个被漏诊或被误治的病例，接"遇到这种情况，我会问三个问题"。
- **语气**：提问式、给判断标准、不急于下结论。常用"第一问是……""如果答案是肯定的，下一步"。
- **优势**：桥章和工具章最稳；读者能带走判断顺序；适合做自测和分诊。
- **风险**：居高临下；变成指南朗读；病例变成考试题。
- **约束**：每章至少一处承认不确定（"这一点现在还没有定论"）；至少一处自嘲或口语化打断。
- **样书参考**：Outlive 第 3 章（目标/战略/战术）、营养圣经第 43 章的"四种分析"。

**明确不用的人设：叛逃者。**

"我从体制里逃出来，告诉你真相"这一类人设在中文医疗书里不可用，原因有四条，写进 `state.json` 的 `notes`：

1. **合规**：贬损规范治疗和同行是可截图的红线（`compliance-cn.md` 红线 3、4），营销文案一旦被认定为广告，出版社和作者一起担责。
2. **身份**：体制内医生没有"敌人"，只有同事和制度约束。写"他们骗你"，读者第一反应是"那你呢"。
3. **审读**：出版社医学审读会要求删掉所有对抗性表述，改完骨架就散了。
4. **说服力**：叛逃者人设靠愤怒驱动，愤怒只能维持一章。读者买书是为了能做事，不是为了站队。

替代写法：批判**激励机制和信息差**，不批判人。可以写"门诊平均 8 分钟，很多话来不及讲透""这套流程是为急性病设计的，慢病用起来就别扭"，不写"医生不会告诉你""医院治不好"。

### 1.6 核心承诺写法

一句话，三个成分，缺一不可：

```
读完这本书，你能够 <一个可观察的动作>；
当 <一个具体情形> 出现时，你知道 <一个判断或路径>；
这本书不 <边界：不替代治疗 / 不承诺治愈 / 不给具体剂量>。
```

正例：

- "读完这本书，你能在下次体检前决定要不要加查糖化血红蛋白和腰围；当医生说'先观察'时，你知道该问哪三个问题；这本书不替代你的主治医生，也不承诺你不得病。"
- "读完这本书，你能把家里的一日三餐改成三档可选的做法；当指标进入某个区间时，你知道该复诊还是该挂急诊；这本书不提供任何药物剂量。"
- "读完这本书，你能用四个数字判断自己的代谢处在哪一档；当出现某几个症状时，你知道这周内必须去医院；这本书不承诺逆转任何疾病。"

反例（出现即重写）：

| 反例 | 问题 | 改法 |
|---|---|---|
| 让你年轻 10 岁 | 具体年数承诺 | 改成可观察的动作 |
| 彻底远离三高 | "彻底"是绝对化用语 | 改成"把风险降到可管理的区间" |
| 不用吃药也能降血糖 | 暗示替代药物（红线 4） | 改成"在规范治疗基础上" |
| 医生不会告诉你的真相 | 贬损同行（红线 3） | 改成"门诊来不及讲清的部分" |
| 一本书读懂所有慢病 | 范围承诺无法兑现 | 缩到 3–4 个病或 4 个杠杆 |

## 二、三幕比例

### 2.1 标准比例（与 `stages/06-architecture.md` 完全一致）

三个部分的比例都按**正文**计算（只算 `07_drafts/` 里的章节），前言、结语、附录另算。

| 部分 | 章数 | 占比 | 功能 | 读者读完之后的状态 |
|---|---|---|---|---|
| 前言 | — | 占全书 3–5% | 一个具体的人 + 旧办法失效的体感 + 本书承诺 | "这说的是我" |
| 第一部分 问题与框架 | 2–3 | 占正文 12–20% | 拆旧解释、命名框架、给路线图 | "原来我一直问错了问题" |
| 第二部分 机制与疾病 | 4–6 | 占正文 30–40% | 讲机制、拆 3–4 个具体疾病、给记分牌 | "我知道该看哪几个数" |
| 第三部分 方法与工具 | 4–6 | 占正文 45–58% | 4 个杠杆 + 执行系统 + 复评 | "我知道今晚做什么" |
| 结语 | — | 占全书 2–4% | 把"怎么活得久"翻成"为什么值得" | "我想再试一次" |
| 附录 | — | 占全书 4–8% | 自测、计划、红线、指标、术语 | "我能查" |

单章 5,000–12,000 字（bridge、essay 章可短到 3,500 字）；全书 10–14 章；预算合计（含前言、结语、附录）在目标字数 ±5% 内。

### 2.2 脚本口径

`scripts/book_check.py` 只统计 `07_drafts/` 里的章节，按部分名汇总后检查：第一部分占正文 12–20%，最后一个部分占正文 45–58%，单章不超过正文 15%，单章不少于 2,500 字（警告级）。下面 2.3 的预算表按全书写，换算成正文占比后都落在区间中段（例如第三部分占全书 45%，正文约占全书 90%，正文占比就是 50%）。

### 2.3 三档可直接套用的预算

| 项 | 8 万字 | 10 万字 | 12 万字 |
|---|---:|---:|---:|
| 前言 | 2,800（3.5%） | 3,500（3.5%） | 4,200（3.5%） |
| 第一部分（章数 × 字数） | 2 × 6,000 = 12,000（15%） | 3 × 5,000 = 15,000（15%） | 3 × 6,000 = 18,000（15%） |
| 第二部分 | 3 × 8,000 = 24,000（30%） | 3 × 7,000 + 1 × 9,000 = 30,000（30%） | 5 × 7,200 = 36,000（30%） |
| 第三部分 | 5 × 7,200 = 36,000（45%） | 4 × 9,000 + 1 × 9,000 = 45,000（45%） | 6 × 9,000 = 54,000（45%） |
| 结语 | 2,000（2.5%） | 2,500（2.5%） | 3,000（2.5%） |
| 附录 | 3,200（4%） | 4,000（4%） | 4,800（4%） |
| 合计 | 80,000 | 100,000 | 120,000 |
| 正文章数 | 10 | 12 | 14 |
| 第三部分 ÷ 正文 | 50% | 50% | 50% |
| 单章最大占比 | 11.1% | 10% | 8.3% |

想提高第三部分的占比，唯一可行的做法是把第一部分压到 2 章（12,000–14,000 字），同时保持第二部分 30%、附录 4%：这时第三部分能到 47–48%，正文占比 52–53%，仍在 `scripts/book_check.py` 的区间内。

### 2.4 允许的偏离

- **Outlive**：12.2% / 36.8% / 49.9%，前言与结语合计 1.1%。它敢让读者等 27,249 字才进第一个疾病章，是因为作者用自传来垫。
- **好能量**：没有三幕，是六段（丧失 → 世界观 → 反派 → 记分牌 → 杠杆 → 执行系统）。它把"记分牌"单独做成 11.8% 的工具章，这是本 skill 可以借的：把指标章写成 bridge 或 plan 型，比塞进疾病章更清楚。
- **营养圣经**：论证 76.6% + 工具 22.4%（该书的 metrics 按清洗后文本计），方法只占两成，因为它是"百科"不是"叙事书"。**这是本 skill 明确不学的结构**：中文原创书的方法部分低于 40%，读者会觉得"说了半天没告诉我做什么"。

## 三、六种章型

章型名称必须与 `scripts/lint_config.json` 的 `types` 完全一致：`argument`、`disease`、`tactic`、`bridge`、`essay`、`plan`。写进 YAML 的 `type:` 字段和后文的 `state.json` 都用这六个小写英文词。

| 章型 | 一句话功能 | 回答读者的哪个问题 | 典型字数 | 在全书的角色 | lint 关键差异 | 样书对应章节 |
|---|---|---|---:|---|---|---|
| `argument` | 换掉读者的旧解释，给一个新名字 | "为什么我以前知道的不管用？" | 5,000–9,000 | 第一部分主力、第二部分穿插 | 不强制清单和红线；研究 1–6/k；我 6–25/k；可带走物间隔 ≤1,800 字 | Outlive 1、2、4、5、14；好能量 1、3、5；营养圣经 1、16、23、36 |
| `disease` | 把一个病写成过程，给查与治的路径 | "这个病会不会落到我头上？" | 7,000–12,000 | 第二部分主力 | 强制章尾清单 + 就医红线；数字 4–16/k；研究 2–8/k；我 5–20/k | Outlive 6、7、8、9；好能量 2；营养圣经 23、32、34、50–58 |
| `tactic` | 把方法拆成 2–4 个可执行组件 | "我今晚该做什么？" | 7,000–12,000 | 第三部分主力 | 强制清单 + 红线；数字 6–18/k；你 4–14/k；可带走物间隔 ≤1,200 字 | Outlive 11、12、13、15、16；好能量 6、7、8；营养圣经 22、24、26、27、39–42 |
| `bridge` | 换气 + 转轴：教读者怎么想，不给新证据 | "接下来该按什么顺序看？" | 5,000–6,000 | 部分交界处 1 章 | 不强制清单和红线；我 12–40/k；问句 1.0–3.5/k；小标题 ≤1.0/k；间隔 ≤2,000 字 | Outlive 3、10；营养圣经 21、43 |
| `essay` | 把"我"放进去，处理恐惧与意义 | "写这本书的人到底怎么想？" | 章 5,000–9,000；前言 3,500–4,200；结语 2,000–2,500 | 第三部分末或全书末 1 章 | 我 15–55/k；研究 0–2/k；小标题 ≤0.6/k；间隔 ≤3,000 字；不强制清单 | Outlive 17 与结语；好能量 9 |
| `plan` | 把方法变成表、卷、流程 | "具体怎么记、怎么测、什么时候复评？" | 正文 8,000–10,000；附录 3,000–5,000 | 第三部分末或附录 | 段落中位 15–60 字；小标题 0.8–4.0/k；数字 8–40/k；强制清单 + 红线；间隔 ≤800 字 | 好能量 第三部分、第四部分；营养圣经 43–49、50–58、59–60 |

### 3.1 各章型的用法与禁用

**`argument`**

- 用：拆旧解释、给新框架、讲一个"反常识但站得住"的机制、解释研究为什么互相打架。
- 不用：给具体操作（会让 lint 的清单要求和可执行性评分落空）；讲病例全程（那是 disease）；一次讲两个论点。
- 结构要点：必须有一段"旧解释的成功史"，否则读者认为你在打倒稻草人。Outlive 第 2 章用塞麦尔维斯和细菌理论做了这件事。

**`disease`**

- 用：一个病的全过程（机制 → 危险因素 → 筛查 → 治疗边界 → 预防），或一个症状群的鉴别。
- 不用：当药品说明书（禁忌和剂量交给医生）；把病写成"可怕的意外"而不写过程。
- 结构要点：先把病写成过程（十年、二十年），再写事件（心梗、透析、失明）。Outlive 第 6 章的核心句是"化验正常不等于代谢正常"。

**`tactic`**

- 用：运动、饮食、睡眠、情绪、用药依从性、复诊、家庭沟通，凡是读者今天能改的。
- 不用：讲机制讲掉一半篇幅（那是 argument）；给"所有人都适用"的方案（必须分基础项和个体化项）。
- 结构要点：先拆成 2–4 个组件，再给每个组件的参数、阈值、频率、失败模式；最后写"不适合谁"。

**`bridge`**

- 用：部分与部分之间、战略与战术之间、两个大主题之间。全书 1 章，最多 2 章。
- 不用：塞新证据（读者会觉得你在拖延）；当目录（目录在前面）。
- 结构要点：一个故事 + 三个区分 + 一张地图 + 一句"所以接下来我们按这个顺序"。Outlive 第 3 章和第 10 章都只有 3,867–10,977 字，却承担了全书的转轴。

**`essay`**

- 用：前言、结语、作者自己的病、一个必须处理的情感主题（恐惧、羞耻、死亡）。
- 不用：当自传（必须有框架）；当免责声明（那是前言的一段）。
- 结构要点：场景 → 暴露 → 框架（心理学或意义层面）→ 行动 → 从"我"到"我们"。Outlive 第 17 章的框架是"创伤树"和 DBT，不是"我曾经很惨"。

**`plan`**

- 用：自测、评分、分档、四周/十二周计划、复评、速查表、附录。
- 不用：当正文的替代（正文没讲清，附录救不回来）；塞剂量（合规风险最高）。
- 结构要点：使用说明（3–5 行）→ 采集（占一半以上篇幅）→ 换算/分档 → 行动 → 复评节点。营养圣经第 45 章的实测配比是"采集 62% + 换算 19% + 输出 8%"，可以直接借用。

### 3.2 章型配比（12 章样本书）

| 部分 | 章 | 章型 | 预算 | 一句话功能 |
|---|---|---:|---:|---|
| 前言 | — | essay | 3,500 | 一个人的一句话 + 旧办法失效 |
| 第一部分 | 01 | argument | 5,000 | 一个被"观察一下"耽误的人：旧解释的时间尺度 |
| | 02 | argument | 5,000 | 旧解释为什么曾经是对的（它的成功史） |
| | 03 | bridge | 5,000 | 记分牌与路线图：四个数、三个问题、一个顺序 |
| 第二部分 | 04 | disease | 7,000 | 第一个病：最致命也最可防 |
| | 05 | disease | 7,000 | 第二个病：最难防，因为沉默 |
| | 06 | disease | 7,000 | 第三个病：最可怕，需要处理恐惧 |
| | 07 | argument | 9,000 | 共同土壤：把三个病接回一个机制 |
| 第三部分 | 08 | tactic | 9,000 | 杠杆一：影响最大、最安全 |
| | 09 | tactic | 9,000 | 杠杆二：最混乱，需要判断标准 |
| | 10 | tactic | 9,000 | 杠杆三：最被忽视 |

合计 100,000（前言 3,500 + 正文 90,000 + 结语 2,500 + 附录 4,000），第三部分占正文 50%、占全书 45%，单章最大占比 10%，全部落在门槛内。这张表只是骨架示例，真实项目按医生的专科替换病种和杠杆，但**章型的顺序和配比不要动**：2 个 argument 拆旧解释 → 1 个 bridge 给记分牌 → 3 个 disease → 1 个 argument 收机制 → 4 个 tactic → 1 个 essay。

## 四、排序规则（12 条，都有样书依据）

1. **先拆旧解释，再给新框架。** 读者不先对旧答案失望，就不会认真听新答案。Outlive 用第 1–2 章、好能量用第 1–3 章、营养圣经用第 1 章做这件事。
2. **记分牌在杠杆之前。** 先让读者能自己测（指标、分数、自评），再给他方法。好能量把记分牌单独做成 11.8% 的一章（第 4 章），营养圣经把"四种分析"放在第 43 章、方法在第 44–47 章。
3. **杠杆按"影响 × 准备度 × 安全性"排序。** Outlive 的顺序是运动 → 营养 → 睡眠 → 情绪：影响从大到小，接受度从小到大，风险从低到高。
4. **疾病按"最致命且最可防 → 最难防 → 最可怕"排序。** Outlive 的顺序是代谢（可防）→ 心血管（可测）→ 癌症（难防）→ 神经退化（最怕）。先给读者一场能赢的仗。
5. **每个"为什么"章后接一个"怎么做"章，成对出现。** Outlive 第 11–12 章（运动：为什么 / 怎么做）、第 14–15 章（营养：认识论 / 实践）都是成对的。单写"为什么"读者会觉得没落地，单写"怎么做"读者不信。
6. **长章后接短章。** Outlive 第 15 章 23,518 字之后接第 16 章 16,274 字（换主题），第 9 章 16,867 字之后接第 10 章 3,867 字（全章最短，纯换气）。连续两章超过 12,000 字，读者会掉队。
7. **第 1 章埋伏笔，中段兑现，结语收束。** Outlive 的"接鸡蛋"在前言埋、第 1 章和第 6 章各回收一次、结语收；好能量的母亲在引言、第 2、3、9 章出现四次。伏笔必须是**一个画面**，不是一句话。
8. **每一部分的第一章负责改变读者的时间尺度。** Outlive 第 1 章从急诊室拉到一生，第 4 章从个体拉到百岁，第 10 章从疾病拉到环境。部分开篇不要写方法，要写尺度。
9. **桥章放在部分交界处，全书 1–2 章。** Outlive 第 3 章（进 Part II 前）、第 10 章（进 Part III 前）。桥章是换气和转轴，不是第二个序。
10. **修辞密度递减：断言 → 承诺 → "你的" → 类目。** 营养圣经 60 章的标题演变是这个规律的教科书：前段用断言和悬念，中段用动词承诺，第六部分切到"你的"，第七、八部分只剩类目名。书的语气要随功能换挡。
11. **越难的行动越靠后。** 运动 → 营养 → 睡眠 → 情绪。读者需要先赢几次，才有勇气处理最难的那一件。
12. **最后一章把"如何"翻成"为什么"。** Outlive 结语只问一个问题："你为什么想活得更久？"这是健康书升格为"人生书"的关键，也是中国医生作者最容易省掉的一步。

反例（写进 `notes`，提醒自己）：

- 开篇先讲医学史三千年，第 4 章才出现第一个病人——读者在第 2 章就走了。
- 把最难的行动（戒酒、情绪、减重）放在第 3 章——读者失败一次就合上书。
- 全书四章都在讲"炎症很重要"，没有一章讲"今晚吃什么"——读者认同但不感激。
- 把桥章写成第二个前言——重复承诺，读者跳读。

## 五、章名与部分名

### 5.1 章名公式

```
记忆点（≤10 字） + ： + 承诺收益或问题（≤18 字）
```

冒号不是必须的，但只要用副标题，副标题必须给"读者能得到什么"或"读者会知道什么"，不能重复主标题。

**七种模式**

| 模式 | 例（示意） | 适合章型 | 注意 |
|---|---|---|---|
| 身体物件 + 承诺 | 胰岛素水位：为什么化验正常，人却在变坏 | disease、argument | 比喻要在章内兑现，不能只在标题出现 |
| 反常识断言 | 化验正常，不等于代谢正常 | argument、bridge | 断言必须有证据章支撑，否则是标题党 |
| 问句 | 吃得少，真的活得久吗 | argument | 只用一个问号，不要"？！" |
| 第二人称 | 你的腰围比体重更早说出问题 | tactic、plan | 一章最多一个"你的"标题，多了像推销 |
| 数字/时间 | 四十岁以后，肌肉每年少 1% | disease、tactic | 数字必须能在正文找到出处 |
| 人物/场景 | 她走到门口又回头 | disease、essay | 主标题不揭示结论，靠副标题补 |
| 类目式 | 指标速查：12 个数字和复查频率 | plan、附录 | 只用于工具章，不用于叙事章 |

**四条检验**

1. **目录测试**：只读 12 个章名，能不能看出"问题 → 原理 → 方法"的推进。看不出，说明章名全是主题词。
2. **截图测试**：单独截一个章名发到群里，别人能不能看懂、想不想点。看不懂就是术语堆。
3. **兑现测试**：副标题承诺的东西，必须在章内出现 ≥3 次（含小标题、清单、案例）。少一次就是过度承诺。
4. **合规测试**：不出现"根治/逆转/揭秘/真相/内幕/医生不会告诉你/最"（见 `compliance-cn.md`）。

忌用："浅谈""漫谈""杂谈"（无承诺）、"XX 病的新希望"（疗效暗示）、"解码 XX"（空）、"你必须知道的 10 件事"（清单书，不是叙事书）。

### 5.2 部分名模式

三种，全书只用一种：

1. **功能名**（默认）：第一部分 问题与框架 / 第二部分 机制与疾病 / 第三部分 方法与工具。清楚、可检索、适合投稿。
2. **比喻名**：从总概念延伸，例如"第一部分 屋顶上的人""第二部分 水从哪里漏进来""第三部分 先关哪个阀门"。更有文学性，但要求三部分同构，且比喻在每部分第一章兑现。
3. **问句名**：第一部分 你问的是对的问题吗 / 第二部分 身体在替你承担什么 / 第三部分 从哪一件开始。适合人设为 B（门诊里说不完的话）的书。

规则：部分名 ≤12 字；三部分必须同构（都用功能名，或都用问句）；不要用"上篇/下篇/续"；部分名里的词要与总概念一致。

## 六、首尾闭环

闭环分三层，三层都要做，缺一层读者会觉得"这本书没写完"。

### 6.1 全书闭环

- 开场的人在结语回来，**只换解释，不换信息**。Outlive 前言是"接鸡蛋"的梦，结语问"你为什么想活得更久"；好能量引言是母亲之死，第 9 章用母亲的低语收束。
- 结语不总结全书，不再给行动清单，只做一件事：把"如何"翻成"为什么"。
- 写法：结语第一段回到开场那个画面（同一个地点、同一句话、同一个动作），第二段给出这十年/这一年后你现在的解释，最后一段把问题交还读者。

### 6.2 部分闭环

- 每一部分的第一章提出一个问题，最后一张回答它。回答的方式是"给一个判断标准"，不是"给一个结论"。
- 部分之间用一句话交接（放在该部分最后一章的最后 300 字），这句话要能被下一部分的第一章直接接住。

### 6.3 章内闭环

- 冷开场的人必须在"案例回收"这一拍回来（见 `references/chapter-template.md` 第 1 节第 6 拍）。不回来，案例就只是装饰。
- 回收的三种合法方式：①他后来做了什么决定；②他问了一个更好的问题；③他成了别人的对照。**不允许**写成"后来他好了"（疗效暗示）。
- 案例回收之后才能进行动清单。顺序反了，读者会把清单当成"给那个人的建议"，而不是给自己的。

三种失败：结语变成全书摘要；开场人物没有回来；为了戏剧性换了一个更惨的人来收尾。

## 七、概念复现规则

概念的价值不在于定义漂亮，而在于读者在第 8 章还能想起来。

| 出现位置 | 写法 | 长度 |
|---|---|---|
| 首次定义章 | 完整定义 + 一个反例 + 边界声明（"这个说法只适用于 X，不适用于 Y"） | 150–300 字 |
| 复现章（第 2–4 次） | 一句话提醒 + 一个新例子或一个新数字，不重复定义 | 40–80 字 |
| 收束章 | 回到框架图，把所有子概念排一次，指出它们的关系 | 200–400 字 |

五种复现手法：

1. **回指**："前面说过的胰岛素水位，在这里又出现了一次，只是这次是在孩子的体检单上。"
2. **加例**：同一概念换一个人群、换一个器官。
3. **反例**：给一个"看起来像但不是"的例子，防止读者滥用。
4. **指标**：把概念接到一个新的数字或检查上。
5. **目录**：在小标题或章名里复用概念词，让读者在目录里看到它。

配额：每章新引入 ≤2 个概念；每章复现 ≥1 个；总概念在每个部分至少出现 1 次；每个子概念全书 ≥3 章（`scripts/book_check.py` 会按 `03_positioning/positioning.md` 的子概念表逐章 grep，少于 3 章报 WARN）。

反面案例：营养圣经造了 ODA、四种分析、基础包、每日十大膳食建议四套命名，读者记不住任何一套——**框架数量控制在 3 个以内**。

## 八、病例分配规则

### 8.1 配额

| 章型 | 主病例 | 次病例 | 作者自己的故事 |
|---|---:|---:|---|
| `disease` | 1 | 1–2 | 0–1 |
| `tactic` | 1（可以是"提出问题的人"） | 0–2 | 1–2（示范动作） |
| `argument` | 1 | 0–2 | 1（自嘲或自实验） |
| `bridge` | 0–1 | 0–1 | 1 |
| `essay` | 1（可以是作者自己） | 0–1 | 贯穿 |
| `plan` | 0–1 | 0 | 0–1 |

### 8.2 四条硬规则

1. **一章一个主病例，同一个 C 编号最多做一次主病例。** 可以做"回访"（在别的章里被提一句），全书上限 2 次。
2. **病例只提出问题，不证明疗效。** 病例的合法功能有四种：提问（他为什么反复就诊）、决策（他在两个方案之间怎么选）、对照（两个人同样的指标不同的人生）、回声（章尾回收）。凡是写成"他用了这个方法就好了"，改成"他决定先做哪一件事"。
3. **每个主病例至少一句原话。** 一句患者原话比作者转述三段更有力。原话必须来自素材库；没有就标"情景示例"。
4. **全书开场的人在结语回收；每章的主病例在章尾回收。** 两条都做到，书才有闭合感。

### 8.3 脱敏与标注

- 只保留化名、年龄段、性别、职业类别。删掉医院、日期、床号、地名组合、罕见病名 + 年龄的组合（可识别）。
- 复合案例必须在首次出现时写明"这是一个复合案例"或"细节已做改动"。
- 正文写法：使用素材库病例的段落前一行写 `<!-- src: C07 -->`；情景示例在首次出现时写"（情景示例）"。`scripts/lint_chapter.py` 会检查"岁 + 患者/先生/女士"的段落有没有来源标注或披露词，两者都没有就 FAIL。
- 每个病例段落必须给一句"这个案例不说明什么"（放在回收段），防止读者把它当证据（`references/patterns/cases.md` 有卡片）。

### 8.4 群像章

需要证明"这不是个例"时，用群像：3–8 个短案例，每个 80–200 字，结构固定为"身份 + 一个数字 + 一句原话 + 一个共同点"。Outlive 第 4 章用 7 个百岁老人做这件事，好能量第 2 章用 17 个小节做同一件事。群像章不再分配主病例。

## 九、可带走物密度

"可带走物"是读者能立刻用出去的东西：一个数字、一条判断规则、一个动作、一句可引用的话、一条清单项。它不是"知识点"。

### 9.1 数量与间隔

| 指标 | 数值 | 依据 |
|---|---|---|
| 密度 | 每 800–1,200 字 1 个 | 好能量实测：每章清单结尾 + 每 800–1,200 字一个可带走物 |
| 单章下限 | 预算 ÷ 1,000（8,000 字的章 ≥8 个） | `stages/08-briefs.md` 的简报要求 |
| 最长空档 | `argument` 1,800 / `disease` 1,500 / `tactic` 1,200 / `bridge` 2,000 / `essay` 3,000 / `plan` 800 字 | `scripts/lint_config.json` 的 `max_takeaway_gap` |
| 章尾 | 最后 25% 必须有清单（`disease`/`tactic`/`plan`） | `scripts/lint_config.json` 的 `ending_list_required` |

`scripts/lint_chapter.py` 认五种锚点：以 `- ` `* ` `+ ` 开头的行、以 `1. ` `1、 ` 开头的行、以 `> ` 开头的引用、以 `|` 开头的表格行、以 `**` 开头的加粗行。**标记符后面必须有空格**，否则不计入。

### 9.2 五种形态与配比

| 形态 | 例 | 每章建议数量 |
|---|---|---:|
| 数字 | "每 1,000 个 50 岁的人里，大约 8 个会在十年内发生心梗" | 3–5 |
| 判断规则 | "腰围超过身高一半，先查空腹胰岛素，不用先查血脂" | 2–4 |
| 动作 | "今晚把碗换小一号" | 3–6 |
| 清单 | 章尾的基础项 / 个体化项 / 就医红线 | 1 组（8–16 条） |
| 一句话 | 可被截图的一句判断 | 1–2 |

### 9.3 位置规则

1. **恐惧后 400 字内必须给动作。** 出现"死亡/癌症/卒中/痴呆/失明/截肢/猝死/瘫痪/透析"后，400 字内要有"你可以/可以先/试试/建议/今天/今晚/明天/下次/去医院/就诊/挂号"或一个列表项。这是 lint 的 WARN，连续触发会毁掉整章的可读性。
2. **每个小标题后 600 字内至少一个可带走物。** 否则那一节只是背景。
3. **章尾 300 字内交接下一章。** 最后 300 字必须含"下一章/接下来/下一步/后面/下一部分"之一（lint 检查最后 300 字）。`essay` 和 `plan` 章不强制。
4. **不要用"多运动""注意饮食""保持好心情"当可带走物。** 这不是可带走物，是口号。改成频率、剂量、阈值或判断条件。
