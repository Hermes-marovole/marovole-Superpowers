# 证据模式卡：证据呈现、等级措辞、风险翻译、不确定性、对立观点

用法：写作前先读 `06_evidence/evidence_bank.md`。正文每个关键论断必须绑定 `[E###]`；一段只用一档措辞（A/B/C/D）。相对风险必须附绝对风险。示范中的数值均为示例，成稿须替换为证据库条目。

说明：文中“全书”指六种章型（argument / disease / tactic / bridge / essay / plan）通用；定位、outline、brief、审稿等属于阶段，不是章内节拍。

## 一、证据呈现

### EVD-01 五源三角测量

- 作用：用多种证据来源交叉验证，避免只看一个随机试验或一个观察性研究。
- 什么时候用：argument / disease 的证据节拍；有争议的干预或药物。
- 操作步骤：1. 列五源：随机试验、队列或流调、动物或机制、人类遗传学（孟德尔随机化）、临床经验。2. 每源一句“能说明什么、不能说明什么”。3. 最后给“我现在的判断”并标置信度。4. 不把五源凑数。
- 原书例证：《超越百岁》第 3 章“结合来自五个不同资料来源的见解”：百岁老人、动物模型、人体研究、机制、孟德尔随机化。
- 中国医生示范：写“他汀该不该吃”时，我把五个来源各放一段：随机试验说明能降低事件；队列说明长期安全性；家族性高胆固醇说明因果；动物机制说明斑块生物学；孟德尔随机化说明终身暴露。最后我才说：“对老赵这种三十年风险很高的人，我倾向于更早干预。”
- 禁用条件：不得把机制证据等同随机试验；不得用五源掩盖证据不足；不得省略局限。
- 自检：1) 五源都相关吗？2) 分别标等级了吗？3) 判断与证据强度匹配吗？

### EVD-02 研究类型前置

- 作用：让读者在正文里就看到“这是随机试验还是小鼠”，不把不同等级混成同一种确定语气。
- 什么时候用：argument / disease 的证据节拍；每段研究开头。
- 操作步骤：1. 每段开头标类型：随机对照、队列、病例对照、动物、机制、专家意见。2. 给强度词：强、中、弱、不确定。3. 段尾一句局限。4. 一段只用一档。
- 原书例证：《超越百岁》全书大量使用“我怀疑、以我的经验、不清楚、有争议”，并区分动物与人体。
- 中国医生示范：写间歇性断食时，我不写“研究证明断食能延寿”，而写：“这是一项小鼠研究（动物证据，弱到中），说明热量限制可能影响寿命；人身上只有短期体重和代谢指标数据（中等），还没有长期死亡率数据（不确定）。”读者知道该信几分。
- 禁用条件：不得只写“研究表明”；不得把动物或机制说成人体结论；不得用标签代替解释。
- 自检：1) 标了类型和强度吗？2) 有局限句吗？3) 读者能复述“有多强”吗？

### EVD-03 一论断一证据 ID

- 作用：把正文每个关键论断绑定到证据库条目，杜绝裸引用与编造。
- 什么时候用：全书；写作与审稿阶段。
- 操作步骤：1. 每个关键论断后标 `[E012]`。2. ID 必须在证据库存在，含来源、类型、等级、绝对风险。3. 一个论断最多 3 个 ID。4. 无 ID 的论断改写为“我的临床经验”（D 级）或删除。
- 原书例证：《超越百岁》用尾注与脚注把每个数据绑定到出处；《好能量》以“见网站”替代，可信度受损。
- 中国医生示范：写“腰围比体重更能预测代谢风险”时，我不写“研究显示”，而写“腰围与代谢风险的关联见 [E031]；体重相同、腰围不同的人风险不同 [E032]”。审稿时编辑只需查这两个编号。没有编号的句子，我改成“我在门诊看到”并标为经验。
- 禁用条件：不得编造 ID；不得一个 ID 支撑多个不同结论；不得用 ID 装饰常识。
- 自检：1) 每个 ID 都能在证据库查到吗？2) 一个论断不超过 3 个 ID 吗？3) 无 ID 的句子处理了吗？

### EVD-04 证据密度与论点重要性

- 作用：核心框架章证据最扎实，方法章可引指南；避免“重要论点只有一句研究”。
- 什么时候用：全书规划；argument 章最严，tactic 章次之。
- 操作步骤：1. 给每章标论点重要性（核心、支撑、操作）。2. 核心章每千字至少 2 个证据点。3. 操作章可引指南或共识，但每个数字必须有来源。4. 审稿先查核心章。
- 原书例证：《超越百岁》机制与疾病章证据密度高，方法章更多是处方与经验；《营养圣经》论证章几乎无注释，是反面教材。
- 中国医生示范：我把全书分三档：核心框架章每千字至少两个证据点；疾病章每个病一个流行病学数字加一个机制来源；方法章允许以指南和共识为主，但“每周一百五十分钟”这类数字也要标来源。审稿先查核心章，因为那里最容易被一句“研究显示”糊过去。
- 禁用条件：不得用证据数量代替质量；不得在核心章用 D 级经验撑框架。
- 自检：1) 核心章密度够吗？2) 每个数字有来源吗？3) 有没有用经验撑框架？

### EVD-05 指南引用三段式

- 作用：引用权威指南而不跪拜，也不贬低；给读者“底线与天花板”的顺序。
- 什么时候用：argument / tactic 的背景或证据节拍；涉及指南目标值时。
- 操作步骤：1. 原文引用条目，准确不曲解。2. 指出适用边界（用于诊断或预防缺乏，不用于优化）。3. 转折“指南是底线，不是天花板；先把底线做到”。4. 不暗示指南被利益集团操控。
- 原书例证：《好能量》第 4 章并列“标准正常范围”与“最佳范围”；第 6 章引用 USDA 指南与行业资助研究。
- 中国医生示范：“《中国居民膳食指南》建议成人每天二十五到三十克膳食纤维，这个量是为了预防缺乏，不是让你达到最佳状态。就像考试六十分及格，不等于六十分是好成绩。”随后补：“指南是底线，不是天花板；先把底线做到，再谈优化。”
- 禁用条件：不得编造指南内容；不得暗示“指南被利益集团操控”而无证据；不得用指南压个体化讨论。
- 自检：1) 引用逐字准确吗？2) 承认适用场景吗？3) 给了“先做到再优化”吗？

### EVD-06 年份与版本

- 作用：防止“用旧研究支撑新结论”，避免书出版即过时。
- 什么时候用：全书证据节拍；审稿阶段做“证据体检”。
- 操作步骤：1. 每条关键结论标年份与类型。2. 核心证据超过十年要复核。3. 区分机制、观察、随机试验、系统综述。4. 书稿完成前问“哪三条最可能被新指南推翻”。
- 原书例证：《营养圣经》2004 年英文版的大量数据在 2018 年中译本未更新，是反面教材。
- 中国医生示范：写维生素 E 时，我不沿用“降低心脏病风险七成”的旧结论，而写：“早期小样本试验提示可能降低非致死性心梗，后续更大规模试验没有重复出总死亡率获益；目前不推荐用它预防心血管病。”并标出两项研究的年份与类型。
- 禁用条件：不得只写“研究表明”不写年份、样本、类型；不得把旧综述当最新证据。
- 自检：1) 核心证据不超过 10 年吗？2) 标了类型吗？3) 写了“后来怎样了”吗？

### EVD-07 复现性检查

- 作用：一个结论有没有被更大试验推翻？写“后来怎样了”，避免把单次研究当定论。
- 什么时候用：argument / disease 的证据节拍；有争议或曾被媒体放大的结论。
- 操作步骤：1. 查该结论后续是否有更大随机试验或荟萃分析。2. 三段写：最初发现、后续验证、现在的立场。3. 若被推翻，明确写“不再推荐”。4. 不掩盖历史错误。
- 原书例证：《超越百岁》对雷帕霉素反复说“不确定”，并区分动物与人体；《营养圣经》未更新维生素 E 结论。
- 中国医生示范：写“维生素 D 防癌”时我写三段：早期观察研究提示低水平与癌症风险相关；随后大型随机试验在一般人群中没有显示补充能降低癌症发生率；现在的立场是“缺乏者补、不缺者不补”，并附证据编号。读者看到的是科学怎么修正自己。
- 禁用条件：不得只引支持自己的研究；不得把“没有证实”写成“已被推翻”；不得省略剂量与人群差异。
- 自检：1) 查了后续研究吗？2) 三段齐吗？3) 被推翻时明说了吗？

## 二、证据等级措辞分级（A/B/C/D）

通用规则：一段只用一档；升级必须给新证据与新 ID；不得用“因此、所以”把低等级证据接到高等级建议上。

### EVD-08 A 级：已有共识

- 作用：给最强证据一个固定措辞，读者一看就知道“这条可以照做”。
- 什么时候用：argument / tactic；指南、共识、大型随机试验一致的结论与核心行动建议。
- 操作步骤：1. 标准句式：“已有共识：……（适用人群：……）。”2. 后接“这条写进指南或共识”并给 ID。3. 只用于多来源一致、无重大争议的结论。4. 不用 A 级措辞包装“多数专家认为”。
- 原书例证：《超越百岁》对吸烟、运动、血压控制的表述接近共识级；《好能量》对“睡眠不足影响代谢”也用确定语气。
- 中国医生示范：“已有共识：对已经确诊高血压的人，减少钠摄入有助于降低血压（适用：大多数成人；不适用：正在低钠血症评估者需医生指导）。这条写进多部指南 [E101]。”随后再给具体做法，不把共识扩写成“人人必须”。读者知道这条可以照做，但也知道边界。
- 禁用条件：不得把单一随机试验或专家意见写成共识；不得省略适用人群；不得用共识压个体化。
- 自检：1) 真有多来源一致吗？2) 标了适用人群吗？3) 有没有过度外推？

### EVD-09 B 级：有较好证据

- 作用：给“方向一致但仍有局限”的证据一个措辞，比 A 弱、比 C 强。
- 什么时候用：argument / disease；多项观察研究加部分随机试验，或随机试验终点与人群有限。
- 操作步骤：1. 标准句式：“有较好证据显示……，但……。”2. 写清局限（样本、终点、随访）。3. 给“我倾向于”的判断。4. 不用 B 级词说“一定”。
- 原书例证：《超越百岁》对很多生活方式干预用“证据不错，但长期死亡率数据仍缺”式表述。
- 中国医生示范：“有较好证据显示，减重百分之五到七并每周运动一百五十分钟，可以降低糖尿病前期进展为糖尿病的风险；但研究对象以中年超重人群为主，老年人、体重正常者的数据较少 [E112]。”接着才给建议；建议里我会写清适用人群和不适用人群。
- 禁用条件：不得把 B 级说成 A 级；不得省略局限；不得用“较好证据”包装机制推测。
- 自检：1) 局限写清了吗？2) 有“我倾向于”吗？3) 没有说“一定”吗？

### EVD-10 C 级：尚有争议

- 作用：给争议一个固定措辞，既不装确定，也不把读者推入虚无。
- 什么时候用：argument / disease 的证据节拍；专家分歧、观察与随机试验冲突、前沿干预。
- 操作步骤：1. 标准句式：“尚有争议：……一方认为……另一方认为……。”2. 写清双方最强证据。3. 给我的倾向与理由。4. 给“在争议解决前，安全的做法是……”。
- 原书例证：《超越百岁》第 2 章激素治疗、第 9 章 APOE 检测、第 5 章雷帕霉素，都是“先公平陈述，再站队，再承认争议”。
- 中国医生示范：“尚有争议：间歇性禁食对长期心血管结局的影响。一方认为改善胰岛素敏感性，另一方认为依从性差、肌肉流失风险被低估。现有随机试验多在十二周内，样本小。在争议解决前，安全的做法是：不追求极端窗口，先保证蛋白质与力量训练。”
- 禁用条件：不得把 C 级写成“科学证明了”；不得用“各有道理”掩盖证据强弱；不得只引一方。
- 自检：1) 双方最强证据都写了吗？2) 给了倾向吗？3) 给了安全做法吗？

### EVD-11 D 级：我的临床经验

- 作用：给个人经验一个明确标签，让它有用但不被当成证据。
- 什么时候用：essay / tactic；指南未覆盖的临床细节、门诊沟通、依从性、决策顺序。
- 操作步骤：1. 标准句式：“在我的门诊里，我常看到……这只是我的经验。”2. 只用于描述现象或决策过程，不用于证明疗效。3. 后面接一个可查证据或一个可执行动作。4. 一段最多一处 D 级。
- 原书例证：《超越百岁》常用“以我的经验”并紧跟机制或研究；作者也承认个人经验的边界。
- 中国医生示范：“在我的门诊里，我常看到体检正常但腰围逐年增加的人，先出现餐后困，再出现甘油三酯升高。这只是我的经验，不能证明因果；能查的是腰围、空腹胰岛素和餐后血糖 [E120]。如果你的情况和这里不同，以检查为准。”
- 禁用条件：不得用 D 级证明疗效；不得把个人经验写成群体规律；不得一段多处 D 级。
- 自检：1) 标了“我的经验”吗？2) 后面接了证据或动作吗？3) 有没有暗示普遍有效？

### EVD-12 等级混用禁令

- 作用：防止一段话从“小鼠”滑到“你应该”，读者误以为证据升级了。
- 什么时候用：全书证据段；审稿必查。
- 操作步骤：1. 一段只用一档措辞。2. 要升级必须给新证据与新 ID。3. 禁止“动物实验，所以人应该”的跳步。4. 审稿时用关键词扫“证明、一定、就是”。
- 原书例证：《营养圣经》把补充剂试验与临床结论混写；《超越百岁》偶有把动物与人体并置的段落，需读者自行分辨。
- 中国医生示范：审稿时我看到一段写“小鼠实验发现 X，因此建议患者多吃 Y”，就拆成两段：第一段标“动物证据，弱”；第二段写“在人体上，目前只有观察性数据 [E130]，所以我只建议缺乏者补充”。中间不加“因此”，加“这还不能说明”。
- 禁用条件：不得用“因此、所以”连接跨等级证据；不得把机制推演写成临床结论。
- 自检：1) 一段只有一档吗？2) 升级给了新证据吗？3) 有没有跨级“因此”？

## 三、风险翻译与不确定性

### EVD-13 相对风险转绝对风险

- 作用：防止“增加 24%”吓到读者，让他们看到每 1000 人多 1 例的真实尺度。
- 什么时候用：argument / disease 的证据或风险节拍；药物、筛查、激素、补充剂。
- 操作步骤：1. 找相对风险、风险比或 hazard ratio。2. 换算绝对风险、每千人增加数、NNT 或 NNH。3. 一句话同时给两者。4. 说明基线风险、时间窗、适用人群。
- 原书例证：《超越百岁》第 2 章：激素治疗相对风险增加 24%，绝对风险仅增加 0.1 个百分点，约每 1000 人多 1 例。
- 中国医生示范：更年期门诊，刘姐说：“网上说激素让乳腺癌风险增加百分之二十四。”我说：“这是相对风险。放到一千个人里，可能只多一例；对你还要看症状、骨折风险、家族史。”她问到底吃不吃。我说：“我们先算你属于哪一类，再决定。”
- 禁用条件：不得用绝对风险淡化真实危害；不得省略基线或时间窗；不得把 NNT 写成“吃几年一定受益”。
- 自检：1) 同时给相对和绝对了吗？2) 说明基线了吗？3) 给了适用人群吗？

### EVD-14 风险沟通四件套

- 作用：把“有风险”说成可决策的信息：基线、时间窗、人群、替代方案。
- 什么时候用：argument / tactic 的证据节拍；任何让读者做选择的段落。
- 操作步骤：1. 基线风险（不治疗会怎样）。2. 时间窗（五年或十年）。3. 人群（谁的研究）。4. 替代方案与不做的后果。5. 最后一句“决定权在你，但要知道这些数”。
- 原书例证：《超越百岁》第 2 章激素治疗讨论同时给相对与绝对风险及适用人群；第 9 章 APOE 给“25 年窗口”。
- 中国医生示范：一位五十五岁女性问要不要用激素。我写四行：不治疗，她这个人群十年骨折风险约多少；治疗，乳腺癌绝对风险增加多少；研究人群多为六十岁以上；替代方案是负重运动与钙和维生素 D 评估。最后写：“决定权在你，但要知道这四个数。”
- 禁用条件：不得只给风险不给基线；不得省略“不做”的后果；不得替读者做决定。
- 自检：1) 四件套齐吗？2) 有“不做”的后果吗？3) 决定权交还了吗？

### EVD-15 不确定性三句

- 作用：用固定三句标记不确定性，既不装确定，也不把读者推入虚无。
- 什么时候用：argument / essay 的争议或前沿节拍；APOE、雷帕霉素、断食等。
- 操作步骤：1. “我怀疑”或“我倾向于认为”表达判断。2. “数据还不清楚”或“仍有争议”标证据空白。3. “在你身上，还要看……”交还个体。4. 三句后必须给一个可行动作。
- 原书例证：《超越百岁》第 3 章：“在生物学中，我们很少能像数学那样明确地证明任何东西。”第 5 章对雷帕霉素反复说“不确定”。
- 中国医生示范：写 APOE 检测时我用三句：“我怀疑 e4/e4 的风险被过度简化了；数据还不清楚，尤其是不同人群；在你身上，还要看家族史、血压、血糖、睡眠和运动。”患者说：“所以不是判死刑？”我说：“不是，是一张需要提前规划的时间表。”
- 禁用条件：不得每段都“不确定”；不得在不确定后不给动作；不得用“科学无定论”逃避判断。
- 自检：1) 区分了事实、判断、猜测吗？2) 给了动作吗？3) 有没有虚无化？

### EVD-16 对立观点五步

- 作用：把争议写公平，让不同立场的读者都愿意读，同时保留作者判断。
- 什么时候用：argument 的证据节拍；激素、他汀、筛查、生酮等。
- 操作步骤：1. 把主流或对立观点说到最强。2. 指出局限与证据缺口。3. 明确站队“我倾向于……”。4. 承认争议仍在。5. 把最终判断交还读者或患者。
- 原书例证：《超越百岁》第 2 章激素治疗、第 9 章 APOE、第 5 章雷帕霉素，都是“公平陈述、明确站队、承认争议”。
- 中国医生示范：写激素治疗时，我先写指南为什么谨慎（WHI、乳腺癌风险），再写它的局限（研究对象多为六十五岁以上无症状女性），然后说：“对有症状的围绝经期女性，我倾向于个体化讨论。”最后补：“这不是所有人都适用，要看你自己的风险谱。”
- 禁用条件：不得用“平衡”掩盖利益冲突；不得把双方写成一样强；不得点名贬低同行。
- 自检：1) 对立观点说到最强了吗？2) 明确立场了吗？3) 选择权交还了吗？

## 反例（不要照做）

### EVD-R1 “研究表明”裸句

- 错在哪里：没有年份、研究类型、样本量、适用人群，读者无法判断可信度，审读也无法核查。
- 为什么危险：容易被当成编造；同类句子里只要有一条错，整章可信度崩塌。
- 改成什么：按 EVD-02 标类型与强度，按 EVD-03 绑 ID，按 EVD-06 标年份。句式：“一项纳入 X 人的队列研究（中等）[E###]，随访 Y 年，显示……，但……。”
- 自检：1) 有类型、样本、年份吗？2) 有 ID 吗？3) 写了局限吗？

### EVD-R2 只给相对风险制造恐慌

- 错在哪里：只写“风险增加 24%”或“降低一半”，不给绝对风险与基线，违反合规要求（相对风险必须附绝对风险）。
- 为什么危险：读者会高估危害或高估收益，做出停药、拒绝筛查等决定。
- 改成什么：按 EVD-13 同时给相对与绝对风险、每千人例数、NNT 或 NNH，按 EVD-14 给基线、时间窗、人群、替代方案。
- 自检：1) 有绝对风险吗？2) 有基线和时间窗吗？3) 有没有用“降低一半”代替绝对数？

### EVD-R3 把动物或机制证据说成人体结论

- 错在哪里：写“小鼠延寿 13%，所以人也能”，或用机制推演直接给临床建议，跨级推断。
- 为什么危险：读者可能自行购买药物或补充剂；剂量与物种差异被抹掉。
- 改成什么：按 EVD-12 拆段，按 EXP-19 写“动物实验是路标，不是处方”；人体部分只写现有证据等级，并明确“不能按体重换算剂量”。
- 自检：1) 有没有跨级“因此”？2) 标了动物证据吗？3) 明确禁止自行用药了吗？

### EVD-R4 贬低监管警告

- 错在哪里：写“标签上的警告是多虑了”“不必理会”，削弱读者的安全防线，也不符合医生作者的审慎义务。
- 为什么危险：读者可能超量使用补充剂或忽略相互作用；出版社医学审读会要求删除。
- 改成什么：原文引用警告，写证据现状与监测建议。句式：“我国规定……需标注……；目前证据显示低剂量短期风险很低，但长期高剂量与……相关，建议长期使用者每 6 个月评估一次。”
- 自检：1) 原文引用警告了吗？2) 给了证据现状吗？3) 给了监测方案吗？
