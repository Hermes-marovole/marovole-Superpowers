# 《营养圣经》逐章结构表（Atlas）

> **怎么用这份结构表**
> 1. 只在写某一类章节前查，不要通读。`stages/06-architecture.md` 只读文末"全书汇总表"，用它校准三幕比例、章长和章型配比。
> 2. 查法：汇总表定比例 → 按章型找 2–3 个同型样本 → 读它的"节拍序列"和"给 AI 的结构提示" → 只抄骨架，不抄内容。
> 3. 本表用的是原书章型（A 论证 / B 目录 / C 工具 / D 病症 / E 阶段 / F 系统），与本 skill 的 `argument / disease / tactic / bridge / essay / plan` 不是一一对应；映射见文末"章型映射"。
> 4. 字数、占比和节拍百分比都是分析估计，用来定预算，不是验收标准；验收以 `scripts/lint_config.json` 和 `scripts/lint_chapter.py` 为准。
> 5. 中文本是译本，句子偏长、代词偏多，只参考比例，不要照抄句长和段落长度。

**用途**：给"中国医生写 8–12 万字叙事型大众健康书"的 AI skill 提供可调用的结构件清单。本表只记录**结构事实**，不评价营养学主张。

**统计口径**
- 字数为汉字数（不含英文扉页、脚注、标点），按章边界统计。
- "引用"为本章内出现的"第 X 章"次数，已扣除本章标题本身。
- 章型：**A** 论证型｜**B** 目录型｜**C** 工具/方案型｜**D** 病症条目型｜**E** 阶段型｜**F** 系统型（以器官为中心，机制+问题+方案）。
- 全书 60 章分布：A 22｜B 9｜C 8｜D 9｜E 4｜F 8。

# 九、八章详细拆解

## 9.1 论证型 · 第 1 章（3,253 字）

- **首句**："这本书是达到目标的一个方法——这个目标就是健康。"（26 字）
- **节拍占比**：
  | 节拍 | 行号 | 字数 | 占比 |
  |---|---|---|---|
  | 重定义健康 | 253–283 | 573 | 17% |
  | 树敌（医疗体系批判） | 284–362 | 1,766 | **54%** |
  | 新框架（基因×环境） | 363–409 | 914 | 28% |
- **小标题命名**：名词 + 破折号 + 判断（"卫生保健——增长最快的失败产业"）；概念名（"健康的新理念"）。
- **结构判断**：一半以上篇幅用于"清算旧体系"，真正的正面框架只占 28%。**这说明论证型开篇的重心不在解释，而在让读者对旧解释失望。** 全章无清单，是全书写作中唯一的"纯立场章"。
