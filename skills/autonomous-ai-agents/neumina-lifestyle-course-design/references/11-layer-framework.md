# 11-Layer Framework — Full Recipes

Provenance: anti-inflammatory 14-day course + detail copy + design meeting (2026-09-02).

## Layer recipes

### ① One-line positioning

```text
先看清你现在的 {状态隐喻} 有多大，再用 14 天，一点一点把它 {动作}。
```

| Theme | Metaphor | Action |
|-------|----------|--------|
| Anti-inflammatory | 火 | 浇下去 |
| Cortisol | 弦 / 压力警报 | 松下来 / 调低 |
| Sleep | 开关 / 夜班保安 | 准点下班 |
| Glucose | 过山车 | 铺成缓坡 |

Rules: one metaphor for entire course; teach one restatable behavior; no extreme deprivation pitch.

### ② Opening resonance

~6 daily “off” signals. Land on:

```text
体检单写着都正常，可你就是浑身不对劲。
```

Then name the shared shadow mechanism in plain language.

### ③ Short mechanism

1. Split two concepts (acute vs chronic; normal stress vs chronic high load)
2. 3–4 sources (body fat / gut / diet / stress-sleep — theme-specific)
3. One closing line: managing X = removing which fuel bundles

Forbid: long pathology, scare tactics, absolute causation.

### ④ Core rules (“constitution”)

Must ship together:

| Piece | Role | Anti-inflam | Cortisol |
|-------|------|-------------|----------|
| Formula | Daily/meal checklist | 抗炎餐盘 | 降皮质醇日节奏盘 |
| 三增三减 | ≤6 memorables | +veg/Ω3/ferment; −sugar/refine/fry/processed meat | +sleep buffer/breath/stable-protein; −late caffeine/night scroll/crash fasting |
| Green list | Encourage | foods | foods + habits |
| Red list | Triggers | pro-inflam foods | pro-cortisol triggers |
| Unified params | Executable defaults | oil/cook priority | caffeine cutoff / wind-down |

Principle: **explain first, practice daily.**

### ⑤ Day 0 baseline

1. No knowledge, no plan shown
2. Capture “usual day” evidence only (photos / logs / scales)
3. Score 0–100
4. One-line read + 14-day upside

Why: uncontaminated baseline; strongest start hook = “see yourself.”

### ⑥ Two-week arc

```text
W1 · 清空打底 — subtract triggers
W2 · 修复养成 — install recovery
```

| Node | Job |
|------|-----|
| Day 1 | Cognition + env clear (kitchen / bedside / phone) |
| Day 2–6 | One rule/day |
| Day 7 | Week-1 review |
| Day 8–13 | Build / stabilize |
| Day 14 | Summary + 3 long-term keeps + graduation |

Meeting patches: front-load high-value tactics; declare strict demo; AI/preference swaps OK.

### ⑦ Daily quartet + enhancers

```text
① theme  ② single task  ③ demo  ④ check-in evidence
```

Enhancers (meeting-validated):

- Daily micro-knowledge (matches today’s goal, collapsible)
- Mini Quiz (participation bonus; wrong answers don’t punish)
- Emotion unlock (“今天有点难？” → encourage + breath; **do not skip the day**)

### ⑧ Scoring + feedback

- Minimize required check-ins (e.g. ≥1 evidence)
- Dims machine-scorable or self-reportable
- Every low dim → **replace/add** template, never scold

Template:

| Dim | Pts | Full logic | Penalty logic |
|-----|-----|------------|---------------|
| A–D | 20 | … | … |
| Context | 10 | season/scene | — |
| Red hits | −20 | — | −5 each |

### ⑨ Weekly review fields

- Completion rate
- Score mean vs baseline / prior week
- Somatic 1–5 × 5 theme items
- Objective × 2 (waist, sleep hours, stress score…)
- One encourage + **one** improvement focus
- Day 14 extra: 3 long-term keeps + comparison chart + upsell/next course

### ⑩ Bonus + supplements

- **Bonus:** same-direction, optional, “每日锦囊” random 1
- **Supplements:** 3 evidence tiers; rules = foundation first, replete deficits, moderate + cite; product link OK, never forced
