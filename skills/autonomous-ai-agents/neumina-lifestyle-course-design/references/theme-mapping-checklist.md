# Theme Mapping Checklist (13 slots)

Fill in order before writing prose. Empty slot = do not start Day-by-day yet.

## Slots

1. **主题隐喻** — one image for the whole course  
   - Example: 火 / 弦 / 开关 / 过山车  

2. **共同根源一句话** — plain-language mechanism name  
   - Example: 慢性低度炎症 / 压力轴节律紊乱  

3. **核心公式** — daily or per-meal checklist object  
   - Example: 抗炎餐盘 / 降皮质醇日节奏盘  

4. **三增三减** — exactly six memorable rules  

5. **绿/红名单** — food + behavior + environment  

6. **基线采集物** — photos? scale? sleep log? caffeine timeline?  

7. **评分 6 维** — each must drive a feedback line  

8. **W1 减法 6 日主题** — clear triggers (Days 1–6)  

9. **W2 加法 6 日主题** — install recovery (Days 8–13)  

10. **体感 5 项 + 客观 2 项**  

11. **加分 3 项 + 补剂 3 梯队**  

12. **合规** — unfit audiences + seek-care red flags  

13. **产品补丁开关** — Quiz / emotion / AI / beans / share / cost tiers on/off  

## Output filenames

```text
两周{主题}课程设计_YYYYMMDD.md
{主题}课程详情页文案_小程序_YYYYMMDD.md
（可选）PLAN-vN.md  // meeting gaps only
```
