# 关键帧与 H3 提示词

## 人物和场景定妆（K0）
先出一张定妆图，之后所有姿势都照它来，保证人、衣服、场景前后一致。

7 天轻松开练用的定妆描述（16:9）：

    写实摄影，横屏16:9画幅，中全景固定机位平视，镜头不拉近、视野开阔宽松。
    现代极简纯色浅灰室内演播室，柔和干净的平整暖灰背景墙，浅灰防滑地胶。
    一位28岁左右的中国女性健身教练，利落整齐高马尾，雾霾蓝无袖修身瑜伽背心 + 深灰色高腰瑜伽裤。
    人物居中，左右空间充裕，头顶和脚底宽裕留白，镜头不推近。
    均匀柔和漫反射光，无任何文字、无字幕、无水印、无杂物。

公司号八段锦（9:16）：40 岁左右女性，不要太年轻也不要显老，浅色练功服，晨光公园草地。

## 姿势关键帧
- 每个运动模式出 2 张：起始姿势 A、顶点姿势 B。要停顿的动作（平板支撑、臀桥停顿）A 和 B 就是同一个姿势的两种静态状态。
- 姿势描述照权威动作要点写，带关节角度、朝向、哪只手哪条腿。八段锦用健身气功管理中心的标准；课程动作用课程方给的拍摄对照表。
- 侧面机位的两张图都必须是纯正侧面：

      正侧面90度侧视视角（纯侧面视角，绝非正面，绝非斜侧角）……
      椅子完全呈正侧面（椅背在画面一侧，椅面与地面平行）……
      人物呈完全的正侧面坐姿（身体朝向画面右侧，侧面轮廓分明，仅能清晰看到单侧肩膀与手臂）……
      头顶上方留白约占画面高度30%，脚底有充足留白，全身及椅子完整入镜，镜头不推近。

- 出图后先检查朝向：用姿态估计（macOS Vision body pose 或 mediapipe）量双肩投影宽度占画面宽度的比例。纯侧面约 ≤0.005，正面约 0.07。A 和 B 朝向不一致，H3 就会在每次动作里转身。
- 结尾姿势不对（比如手臂没伸直）就重出关键帧，不要只改提示词。

## 去重
43 个课程动作合并成 23 个基础运动模式。同一模式的动作共用片段，只改标题和处方：
- 徒手蹲 / 触椅深蹲 / 原地半蹲 → squat
- 台面俯卧撑 / 墙面俯卧撑 → pushup
- 臀桥 / 顶部停顿臀桥 → glute_bridge
- 髋铰链 / 扶椅鞠躬 / 扶墙鞠躬 → hip_hinge
- 坐姿勾脚提踵 / 坐姿脚踝活动 → seated_ankle
再按道具和体位分批（地面垫上、椅子、墙面或台面、徒手站立），同一批共用同一张底图，光线和背景就不会漂。

## H3 提示词结构
动作句 + 公共尾巴。公共尾巴（16:9 侧面）：

    写实实拍健身演示画面，横屏16:9画幅，中全景固定机位平视，正侧面90度视角，
    镜头完全不动不推不摇，不拉近，视野开阔宽松。背景现代极简演播室纯色暖灰平整背景墙保持不变，
    浅灰防滑地胶，道具与身体朝向完全保持正侧面不转体。同一位中国女性教练，
    身穿雾霾蓝无袖修身瑜伽背心与深灰色高腰瑜伽裤，动作缓慢、匀速、标准、连贯，
    呼吸自然，神情专注平和。全身始终完整在画面中。无字幕、无任何文字、无水印。

动作句示例：
- 去程：完全正侧面90度侧视，她端坐在侧向靠背椅上，身体和椅子保持正侧面不动，一条腿缓慢匀速向前水平伸直抬平，脚尖勾起。
- 回程：完全正侧面90度侧视，身体和椅子保持正侧面不动，抬平的腿缓慢匀速下落屈膝90度踩回地面。

## 生成参数
- `./h3.sh gen "<动作句+公共尾巴>" --seconds 5 --ratio 16:9 --seed 42 --first A.png --last B.png [--turbo]`
- 环境变量 `H3_PREFIX=ps_<shot>_s42`，输出文件名就固定了；subprocess 用 `errors="replace"` 读输出。
- 每条片段失败重试 4 次，间隔 10 秒；已有的片段（>100KB）跳过，支持断点续跑。
- 实测：turbo 约 210–380 秒一条，标准 20 步约 480–520 秒一条。
