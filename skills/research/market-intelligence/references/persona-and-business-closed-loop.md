# 人群画像、付费意愿与商业闭环可行性（Persona / WTP / Closed-Loop Viability）

当任务不是「这个赛道多大」，而是「我们这个产品卖给谁、他们为什么掏钱、这门生意闭环通不通」时，按本手册执行。六步 SOP 的 Step 4/5 在此展开。

---

## 一、顺序铁律：先读自家产品契约，再做人群合成

**必须在跑任何外部调研之前，先读自己产品里已经写死的文案与契约**。人群画像是为了修正产品，不是凭空生成一份漂亮 PDF。

要读的具体文件（按产品形态替换）：

| 产品形态 | 要读的契约 | 要找的字段 |
| :--- | :--- | :--- |
| 内容/课程产品 | 课程 JSON、详情页文案、Admin 编辑字段 | `suitableFor`（适用人群）、课节 `title`/`summary`、价格档、报名需填字段 |
| SaaS / App | 落地页 Hero、onboarding 问卷题面、paywall 文案 | 首屏一句话价值主张、分群问题、定价锚 |
| 电商 / 实物 | SKU 标题、详情页卖点、包装文案 | 主打场景词、规格诉求、竞品对比表 |

**产出物是一个「文案病灶对照表」**，而不是一段感想。典型病灶与改写方向：

| 病灶 | 表现 | 改写方向 |
| :--- | :--- | :--- |
| **教科书视角** | 课节写成「升糖与 GI、GL」「身体怎么处理碳水」；适用人群写成「想搞懂 X 和 Y 区别的朋友」 | 换成用户当天正在经历的场景与身体感受：「同样是吃饱，为什么有的主食养气色，有的专门长小肚子？」 |
| **品类视角** | 卖点写「14 天系统课，含 7 节视频」 | 写「不挨饿、不垮脸，7 天把小肚子收回去」——先给结果，再给交付形式 |
| **无人群限定** | 适用人群是「想健康的人」 | 用搜索证据里带年龄性别的长尾词锁定：「过了 35–40 岁、吃得不多但小肚子顽固凸起」 |

判断标准一句话：**没有任何用户会为了「搞懂某个概念」或「学某个名词」掏钱**。文案里出现学科名词而没有身体感受，就是病灶。

## 二、从 Autocomplete 长尾反推人群（比问卷更硬）

`market_intel_tool.py intent "<种子词>"` 跑出的下拉词里，有三类可直接当画像证据：

1. **自带年龄+性别的限定词 → 直接就是 ICP 边界**
   - 形如 `小肚子大怎么减下去45岁女`、`40岁减肥会不会显老`、`产后多久可以减肥`。用户自己在搜索框里把年龄性别敲了进去，这是最便宜的人群切分验证，比任何问卷分层都可信。
   - 做法：把种子词按「症状词 × 年龄」交叉各跑一遍（`<症状>`、`<症状>+40岁`、`<症状>+50岁`），比较下拉词集合差异。**差异本身就是人群分层的证据**：不同年龄段关心的副作用词不同，说明文案必须分版本。
2. **恐惧词 / 顾虑词 → 直接决定文案必须先拆掉的反对意见**
   - 形如 `会不会显老`、`会不会反弹`、`副作用大吗`、`是不是智商税`、`停药会不会更胖`。
   - 这类词必须出现在定价页或第 1 节课里被正面回答，否则用户在付款前流失。**把恐惧词当成标题的一半**，而不是放在 FAQ。
3. **「吃什么补什么」类词 → 证明课程/工具与实物/订阅的联动付费意图天然存在**
   - 形如 `减肥适合吃什么保健品`、`代谢慢减肥吃维生素b族还是维生素d`、`控糖减肥期间能吃的零食有哪些`。
   - 这是**闭环可行性的最硬证据**：用户不是在等你教育他买补剂/耗材，他自己就在搜。看到这类词，说明「内容 → 实物/订阅」的转化不需要硬推。

**反例警告**：如果下拉词全是「怎么算卡路里」「XX 和 YY 的区别」，说明该品类仍停留在工具/科普需求，付费意愿弱，应优先做免费工具截流而非卖课。

## 三、三级人群画像表（输出结构固定）

不要输出一个人物志故事，输出一张可执行的分层表。每层必须能对应到不同的产品动作与客单价。

| 维度 | Tier-1 主力（占营收 60%+） | Tier-2 冲量 | Tier-3 高复购/口碑 |
| :--- | :--- | :--- | :--- |
| 人口学 | 年龄/城市线/收入/家庭阶段 | 更年轻或更忙，时间稀缺 | 更年长，信任驱动 |
| **痛点原话** | 用第一人称写她/他自己的抱怨，含具体时间与身体感受 | 同 | 同 |
| **JTBD 任务陈述** | 「当我 <触发情境> 时，我想要 <解决方案形态>，以便 <可衡量的结果>」 | 同 | 同 |
| **付费意愿与心理账户** | 给年预算区间 + 她现在已经在为什么花钱（对标物） | 同 | 前端极敏感、后端极高 |
| 对应产品改造点 | 指到具体字段/课节/SKU | 同 | 同 |

JTBD 写法要求：触发情境必须是**一天中的具体时刻**（下午 4 点心慌、体检报告出来那天、换季穿不上裤子），不是「想减肥的时候」。

## 四、商业闭环可行性：四象标杆 + 四阶漏斗

### 1. 标杆选择必须四象齐全（缺一象则论证不成立）

| 象 | 选谁 | 它回答什么 | 必须提取的数字 |
| :--- | :--- | :--- | :--- |
| **A. 上市龙头财报** | 该品类已上市的第一名 | **天花板在哪，以及纯卖内容/软件为什么赚不到钱** | 分部收入与增速、分部毛利率、月活/订阅数、单用户 ARPU、销售费用率 |
| **B. 国内百亿级同类** | 同一人群、同一漏斗、做到数十亿以上营收的国内玩家 | **这套漏斗在国内真的跑通了，且跑通了什么形态** | 总营收量级、体验价、正式价、加微/进群链路、单班人数、销售提成结构 |
| **C. 全球龙头** | 该需求在全球的最大付费平台 | **这个人群在全世界都愿意付钱，且 AI+人混合服务的人效上限** | ARR、付费用户数、客单价、1 名顾问可服务人数、向上卖的第二三层产品与价格 |
| **D. 相邻巨头/被战投者** | 刚被大厂战投或收购的相邻玩家 | **战略价值被谁认领了，闭环缺的那块拼图是什么** | 持股比例、用户/数据规模、接入的生态入口 |

必须同时写出每家的**硬伤或暴雷点**（合规处罚、退费潮、销售费用失控、用户流失原因），并在下一列直接写「我们不能踩的那一条」。只写好话的竞品分析没有决策价值。

### 2. 四阶漏斗（内容/课程/工具类产品通用）

```text
第 1 阶 前端钩子（自负盈亏）
  低价体验品（¥1–¥19.9 / 免费工具）+ 采集分群字段 + 引导加顾问
  目标：门票收入覆盖获客成本，加微率 ≥60%
      ↓
第 2 阶 低成本建立专业信任（AI + 1 名人类顾问，人效 300–400 人）
  逐日小任务 + 拍照/数据打卡自动点评 + 第 5–6 天出具个人诊断
  目标：把「通用内容」变成「针对你的结论」，这是唯一无法被免费短视频替代的东西
      ↓
第 3 阶 中端打包（首单毛利层）
  深度内容 + 首月实物/耗材/服务，¥199–¥399
  转化话术必须建立在第 2 阶诊断出的个人缺口上，而不是通用卖点
      ↓
第 4 阶 LTV 订阅（真正的利润）
  判断 → 方案 → 服用/使用 → 复评 → 调方，按周期续订，年客单 ¥1,200–¥2,400
```

### 3. 单位经济表（按 1,000 名前端用户测算，必须落到表）

列：漏斗阶段 / 转化率假设 / 人数 / 客单价 / 营收 / 毛利率与成本说明。最后一行给出**池均产值**与**CAC 盈亏平衡点**（「只要单个前端获客成本低于 ¥X，首月即正现金流」）。

三个必写口径：
- 转化率要写两种分母（占总报名 / 占加微人数），否则别人无法复核。
- 实物成本必须来自 1688 同类代工价或已披露 BOM，不能拍脑袋。
- 毛利率分层写清：内容层（≈70–80%）、实物层（30–45%）、订阅服务层（≈80%）。

### 4. 与已有基建对齐，而不是假设从零开始

写闭环前先扫一遍自己的仓库，列出**已经做完的技术前置**（支付通道、完播/使用埋点、拍照识别、顾问触点、Admin 配置能力），逐条标到漏斗的哪一阶。结论句应形如「距离跑通只差 A 和 B，而 A/B 都不是技术问题，是文案与人群问题」——这比「建议做 XX」有力十倍。

## 五、必须做的三个反方质询（针对人群与闭环，而非泛市场）

1. **「巨头有 X 千万月活和免费内容，凭什么用户给你钱？」**
   → 只能靠「多症状交织 + 个人化结论 + 有人负责复评」来答；如果答案是「我们内容更好」，方案不成立。
2. **「你怎么避免重蹈同类玩家的暴雷？」**
   → 逐条对照其暴雷点（高压电销、虚假功效承诺、高价水课、分期诱导），写明我们的替代做法与合规边界。
3. **「上线第一批的转化率凭什么翻倍？」**
   → 必须落到 48 小时内可改完的具体字段与文案（标题、适用人群、课节名），不能只给战略建议。
